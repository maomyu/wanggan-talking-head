# 研究依据与适用范围

查阅日期：2026-10-18。技能主体为本次原创的口播版式判断，不是下面资料的翻译或摘抄。

- 用户给出的动效导演提示词：提供专家角色、完整执行判断、具体工艺与验证意识。遵从用户要求保留提示词深度，排版模块只承担自身职责。
- 用户确认的纸本批注、几何印刷画风及其真实样片：提供本轮字体、色彩、材质和人物处理的交接条件。批准画风方向不等于已经批准本轮所有排版。
- [W3C《中文排版需求》](https://www.w3.org/TR/clreq/)；本次查阅的[固定版本为 2026-10-07 草案](https://www.w3.org/TR/2026/DNOTE-clreq-20261007/)。参考其中文行首行尾禁则、不可分割字符组合和中西文混排议题。它是工作草案，不是短视频平台强制规范，也不提供本技能中固定字号和安全区。
- [WCAG 2.2：Understanding Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文字 4.5:1、大字 3:1 的对比度参考。参考文件同时提示细字、抗锯齿与显示条件会影响实际感受。本技能借用其阅读原则，不声称静态视频样帧因此取得无障碍认证。
- 原研究仓库 [alchaincyf/huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion)：沿用上一轮已研究并固定在本地的资料，启发画风、分镜、构图、字幕和整片节奏需要协同验证。本轮没有把它的整套制作流程或每条动效规则转为排版强制要求。

## 本轮验证边界

两套画风、同一人物、9:16、五种静态阅读任务。检查真实文字、字体覆盖、空间关系、对比和缩小后的可读性。没有本轮新片段的进出动画、人声同步、字幕阅读时长和跨内容测试；这些留在实际应用中验证。无外部独立评审。
