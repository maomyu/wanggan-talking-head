# 实测范围与证据使用

研究日期：2026-10-18。工程保存在 `test/剪辑转场研究_20261018/edit-study-01`，不会自动安装到全局。

沿用既有虚构数字人的30.1667秒原片，剪成约22.04秒；未重新生成脸、声音、画风或素材。保留观点的顺序、否定词“不一定”、三个动作与完整结论。删减的195帧包括开头问句、8帧停顿、两句完整补充和尾部留白。长度减少约26.9%，只说明编辑结果，不证明播放或商业表现提升。

本次比较纸本批注、几何印刷两套既有视觉语言。它们使用同一 EDL、同一参考音轨，便于判断不同材料能否承担同一种剪辑目的。只验证一段素材、两种画风、9:16、24fps。跨内容适配由用户决定在后续真实应用中继续迭代，不作为本轮前置条件。

工程证据：
- `edit-plan.json`：原片哈希、保留与删除区间、每种断点目的、声画差异。
- `timing.json`：统一输出帧、字幕和动效触发。
- `qa/audio-conform.json`：原声拼接采样数与淡化范围。
- `qa/*check-final.json`：明确采样时间的运行、布局与对比检查；工具若 motion.enabled=false，不能据此声称全量动效自动合格。
- `qa/encoded-verification.json`：实际编码的规格、声音与参考音轨对比、抽帧与最终文件哈希。
- `qa/cut-coverage.json`：实际编码剪点的遮挡颜色检测，检查人物区域是否真被覆盖；不是靠 CSS 存在来判断。
- `qa/browser-final.png`：最终对照页播放/跳转的浏览器证据。浏览器截图是可用性证明，不能替代最终 MP4 的帧检查。
- `ledger.md`：修正记录及仍需判断的部分。

本次为作者自查，没有独立审片代理，没有真人口型逐字真值、平台留存数据或全套多画幅验证。ASR 词时间只是定位候选；编码音频相关性检查只能证明轨道接续和导出，没有证明每个词的听感与韵律都完美。最终自然程度仍应结合实际听看判断。

## 参考来源与取舍

- 用户最初的完整动效导演提示词：继承事实可追溯、内容驱动转场、确定时间线、先短测、实际抽帧和迭代记录；改为口播的语义、原声与阅读优先，不照搬“只在节拍切”“必须不停运动”等演示片硬规则。
- 已完成的画风、排版、动效研究：继承材料、人物框与字幕区域，不把本轮当重新设计。
- 固定版本 HyperFrames 0.8.171 的 creator-editing-recipes、媒体/音频合同：片段裁切、分离音轨、声画出入点与统一播放器控制。
- 本地 catalog 查询 `content cover wipe` 命中 `transitions-cover`、`directional-wipe` 等。此案例只需要已有画风中的不透明平移遮挡，使用既有 GSAP 与材料，自行编排内容，不安装整套横版转场秀，也不引入其他效果。
