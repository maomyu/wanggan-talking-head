# 模块交接：先决定剪什么，再决定怎样交接

本项目研究接口，按内容复杂度增减字段，不要求未来每条片固定使用同一套 JSON。

| 模块 | 本模块读取 | 本模块回传 |
|---|---|---|
| 画风 | 色彩、字体、材料、认可样帧 | 本次转场使用哪些既有材料；不得为了遮挡临时引入新画风 |
| 排版 | 人物框、字幕基线、标题与图解区域 | 哪帧起让出人物区、何时读完、剪点附近哪些区域必须保持 |
| 动效 | 人物让位、笔线/块面、图解展开等运动语汇 | 触发帧、完全遮挡帧、底片切换帧、完成帧、不能晃动的阅读对象 |
| 声音 | 原声、已有配乐与处理要求 | 源出入点、人声微调、J/L 覆盖关系、接缝与淡化采样数 |
| 主流程 | 原片、脚本、事实来源、最终交付规格 | EDL、时长、原意核对、实际渲染文件与验证记录 |

## 时间合同

区间采用 `[in,out)`；视频以源生帧率计帧，音频按整数采样。总时长由 EDL 计算，不在不同模块各写一份近似值。剪辑调整后重新映射字幕与动效，不能只替换视频。

每个 shot 至少记录 sourceIn/sourceOut、outputIn/outputOut、purpose。视频与声音不一致时额外记录 sourceSeconds 和原因。别把字段名相似当成时间基相同。

## 内容遮挡的交接单

- 画面交接材料：纸本是浅色纸页，几何是黄色实块。
- 入场：249–256帧；256–257帧完全覆盖；底片在257帧换。
- 退场：258–265帧。字幕始终在覆盖层上，页眉/页脚在遮挡期间关闭，防止透过或错误对比。
- 第二处340帧剪点：336帧起不透明底色遮住人物，图解保留到344帧。并非把两张正在讲话的脸叠化。
- 结尾379帧剪点：保持全屏图文覆盖，390帧揭开底色；人物随后完成回归。
