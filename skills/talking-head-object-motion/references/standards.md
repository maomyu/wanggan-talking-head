# 物体动效标准库

本库为设计标准，当前不标为通用渲染器。按语义选择必要项，不强迫全片把所有项都用一遍。新增标准以实际差异为准，改配色或纹理不重复增加画风。

## 纸页位移与翻转 · `paper-shift-flip`

纸页先有动机位移，再围绕明确轴心交出正反面。

- 适用：解释观点背面、展开原文和纸页交接。
- 避免：翻转过程中继续读小字；错误镜像或穿模。
- 交接：预备、转动、遮字、背面显现、停稳五段帧号。
- 控制字段：objectId, verb, startFrame, settleFrame, endState, path
- 结构依赖：surface.paper
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 印章显现 · `stamp-reveal`

印记落在指定对象上并留下可读结果。

- 适用：已确定的分类、批注或结论。
- 避免：伪造机构认证；每句话都盖章。
- 交接：落点、一次接触、印记内容身份与结果停留。
- 控制字段：objectId, verb, startFrame, settleFrame, endState, path
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

- 适用：把同一物件从问题区带入解释区。
- 避免：相关图片无任务地来回漂；仅终点不遮字。
- 交接：起点、路径、落点、理由及整个路径保护区。
- 控制字段：objectId, verb, startFrame, settleFrame, endState, path
- 结构依赖：由本片语义和共享合同决定

## 归类与比较 · `sort-compare`

- 适用：选项、需要与想要、前后对照。
- 避免：分类重叠；横向位置暗示无依据排名。
- 交接：分类依据、对象ID、组标签与结果读图窗。
- 控制字段：objectId, verb, startFrame, settleFrame, endState, path

## 累积与消减 · `accumulate-reduce`

可追踪的同类单位增加、减少或重新分配。

- 适用：负担、资源、数量关系的示意。
- 避免：把八个示意单位说成实际金额；凭空增减。
- 交接：单位身份、数量前后值、变化原因与示意说明。
- 控制字段：objectId, verb, startFrame, settleFrame, endState, path
- 结构依赖：由本片语义和共享合同决定

## 机制驱动变形 · `mechanism-transform`

变形有输入、约束与结果，关键结构可追踪。

- 适用：压力、伸缩、展开和状态变化。
- 避免：物件无意义液化；把动画当科学模拟。
- 交接：输入、约束、变形前后状态及模拟精度声明。
- 控制字段：objectId, verb, startFrame, settleFrame, endState, path
- 结构依赖：object.volume, object.layered
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 逐步描出与组装 · `trace-build`

按逻辑次序建立结构，已建立部分继续服务下一步。

- 适用：结构解释、步骤与推演。
- 避免：所有线同时画；组装顺序和口播相反。
- 交接：部件依赖、笔顺、完整结构与最终静读窗。
- 控制字段：objectId, verb, startFrame, settleFrame, endState, path
- 结构依赖：object.lines, object.volume, object.symbol
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 局部响应与强调 · `focus-response`

对象只在被讲到时给出一次明确反馈。

- 适用：重音、操作结果、关键词。
- 避免：持续弹跳、闪烁和所有物体同时强调。
- 交接：触发词、响应幅度、回归帧和一处主注意。
- 控制字段：objectId, verb, startFrame, settleFrame, endState, path
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 动作揭示后果 · `reveal-consequence`

前景动作暴露原本隐藏的结果或条件。

- 适用：转折、风险、表里关系。
- 避免：在口播揭示前泄露结论；揭开后没有读图时间。
- 交接：遮挡物、隐藏内容、揭示锚点与结果保持。
- 控制字段：objectId, verb, startFrame, settleFrame, endState, path
- 结构依赖：由本片语义和共享合同决定
