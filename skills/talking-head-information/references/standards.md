# 信息组织标准库

本库为设计标准，当前不标为通用渲染器。按语义选择必要项，不强迫全片把所有项都用一遍。新增标准以实际差异为准，改配色或纹理不重复增加画风。

## 文学引句 · `literary-quote`

把真实引文作为被解读的对象，并明确出处与语境。

- 适用：文本解读、观点引用。
- 避免：编造名人名言；断章取义；无引文硬加。
- 交接：逐字原文、来源、解释与作者观点分层。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 选项对照 · `option-comparison`

用共同维度比较真实可选项，展示成立条件。

- 适用：选择、需要与想要、方案判断。
- 避免：文案无比较也强分左右；掩盖量纲差异。
- 交接：对象、比较维度、证据与结论条件。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 人物寓言 · `character-parable`

以明确虚构或真实有来源的人物行为承载关系。

- 适用：抽象机制、行为后果。
- 避免：让真人说未说过的话；编造真实人物经历。
- 交接：人物身份、行为、后果与寓言/真实标识。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 因果解释 · `cause-effect`

展示条件如何通过机制带来结果。

- 适用：因果明确且来源支持的句段。
- 避免：并列建议画成因果链；相关性冒充因果。
- 交接：条件、机制、结果、限定条件与证据。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 对比与转折 · `contrast-turn`

保留预期，再揭示修正预期的条件或结果。

- 适用：但是、反而、看似与实际。
- 避免：提前泄底；只有换色没有预期变化。
- 交接：原预期、转折锚词、真正改变的状态。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 并列建议 · `parallel-options`

多项处于同一层级，可分别行动。

- 适用：三条建议、多个风险、可选方法。
- 避免：用箭头排成必经步骤；无依据主次排名。
- 交接：共同父主题、每项任务和独立结果。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 过程步骤 · `process-steps`

按先后依赖解释有顺序的过程。

- 适用：操作流程、制作机制。
- 避免：把可选建议排成顺序；遗漏前置条件。
- 交接：步骤依赖、进入条件、输出及失败分支。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定

## 证据与解读 · `evidence-interpretation`

先呈现能核查的材料，再标出据此得出的判断。

- 适用：数据、原文、截图和事实论证。
- 避免：生成图冒充证据；只给结论无材料。
- 交接：证据源、原文边界、标注与推断身份。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

## 问题·机制·应对 · `problem-mechanism-response`

从具体问题进入原因和可行应对，各段有独立任务。

- 适用：科普、方法类口播。
- 避免：所有问题套同一故事；无依据保证效果。
- 交接：问题场景、机制、应对条件与现实限制。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定
- 状态：设计标准；尚无该11模块体系下的通用渲染验收。

- 适用：结尾、段落小结。
- 避免：换一套新图重新讲；无依据增加新结论。
- 交接：复用对象ID、已发生变化和最终记忆点。
- 控制字段：sentenceIds, relation, evidence, assetTask, visibleResult
- 结构依赖：由本片语义和共享合同决定
