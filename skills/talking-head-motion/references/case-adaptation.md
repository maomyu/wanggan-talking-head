# 怎样保留原始案例的深度

用户于2026-10-18在当前会话提供完整动效导演提示词，作为本技能首要参考。主文件保留专家角色、brief、动作工艺、素材身份、共享时间依据、确定性实现、完整编码、评审循环与交付证据。

针对口播模块进行以下适配，避免把整片导演职责全部压进一个模块：

| 原案例的要求 | 口播中的判断 |
|---|---|
| 先做声音、按节拍剪 | 已有人声优先；音乐存在时才协调节拍。语义与阅读不能被音乐牺牲 |
| 每个词约0.3秒 | 中文按短语与真实阅读判断；区分动作时长与完整可读时长 |
| 画面文字不重复旁白 | 普通字幕可以重复人声；避免多层表现文字同时重复 |
| 任何东西不能冻住 | 真人本身持续自然变化；文字与图解的阅读状态允许稳定 |
| 版式永远不重复 | 相同阅读任务可复用结构，动作交接服从内容变化 |
| 只切在节拍、每次换场有嗖声 | 由剪辑与声音模块在实际内容中决定，不作为动效强制规则 |
| 不用线性缓动 | 进出和制动有速度变化；匀速描线等有意使用仍合理 |
| 整片从素材到混音全部代码完成 | 本模块承接真实素材、画风与排版；只实现授权的动效，不擅自重录、混音或发布 |
| 每次派全新独立评审 | 保留独立评审的方法与证据要求；具备授权和工具时使用，否则诚实标注作者自查 |

确定性时间轴与真实输出检查，参考本机HyperFrames core、animation、keyframes技能及其svg-path-draw、anchored-layout-expand规则；实现沿用本地固定版本，未据此安装或刷新全局技能。

示例画风、字幕与人物来自本项目之前的研究产物；全部来源及哈希在实测工程中记录。本轮没有借用外部作品画面或音乐，没有新增传播效果、评分、客户或数据主张。
