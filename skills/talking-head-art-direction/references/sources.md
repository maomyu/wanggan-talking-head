# 方法来源

本 skill 的完整专家提示词根据用户对多样化口播视频的需求编写，并结合本地14秒样片的实际问题修订。

参考仓库：[alchaincyf/huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion)。研究版本：`8a0d7d72ca65fcce6f8ba82c4a6c8dfe35b8422c`。

主要方法参考：

- [跨场景风格提炼](https://github.com/alchaincyf/huashu-art-motion/blob/8a0d7d72ca65fcce6f8ba82c4a6c8dfe35b8422c/references/15-跨场景风格提炼.md)：提取可观察的视觉关系，区分题材、构图和风格语言。
- [一帧先行四条路线](https://github.com/alchaincyf/huashu-art-motion/blob/8a0d7d72ca65fcce6f8ba82c4a6c8dfe35b8422c/references/03-一帧先行四条路线.md)：先用实际画面检验方向，再按条件选择实现路径。
- [口播整片与经验回流](https://github.com/alchaincyf/huashu-art-motion/blob/8a0d7d72ca65fcce6f8ba82c4a6c8dfe35b8422c/references/12-口播整片与经验回流.md)：视觉与口播时间共同工作，按具体问题记录和修正。

这些来源用于方法研究。本包的提示词和示例说明为本项目重新组织的内容，不包含上游代码、角色、字体或视频，也不要求复制其模型分档、固定配额、专用门禁和作者个人偏好。

附带拼版来自本项目实际渲染的纸本批注、几何印刷两条片段，供理解已认可画风的关系；不作为任意新任务的固定人物或画面素材。
