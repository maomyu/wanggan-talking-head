# 八类编排机制与十一类技能协作

这八类定义观众如何跟随解释，独立于画风。19套母画风保持原分类，技术蓝图仍是分支；组件保存可复用的载体或行为。人物主导 presenter、连续图解 diagram 保留为兼容的注意力方向，不算第九、第十种新机制。空间漫游 spatial 至人物现场回应 response 是本轮正式收录的八种具体机制。

## 先决定讲述，再决定画面

先从当前口播确定原句、否定、条件、比较基线与段落关系，为每段写清“对象初态 → 动作 → 可见结果 → 读窗 → 下一段接住什么”。图片承担证据、对象身份、空间参照或状态变化中的明确任务。没有任务不加图；多移动几张相关图片不能替代解释。

用户明确指定的机制优先。未指定时，智能体选一个主机制，必要时在个别段落使用其他机制的局部技法，记录切换理由、交接对象与回归方式，不轮流展示八种效果。`auto`表示等待智能体读懂内容后决策，不是随机选项或固定关键词推荐。CLI不替代智能体理解文案。

| ID / 名称 | 适用关系 | 主动作与交接 | 特别检查 |
|---|---|---|---|
| G01 / spatial / 空间漫游 | 空间、步骤、整体与局部 | 同一总图进入局部，再回到总图；对象保留处理结果 | 方向稳定；拉远标签仍读得清；不穿越无关空间 |
| G02 / relay / 同物接力 | 同一问题、证据或对象贯穿段落 | 同物承接、展开、转交；交接前后保持身份与位置关系 | 不偷偷换物；不是每段新卡片配同一种滑入 |
| G03 / assembly / 拆解与组装 | 部分与整体、结构与职责 | 拆件、解释、重新归位，结尾看见完整关系 | 不把并列建议伪装成物理构造；部件无故消失必须修 |
| G04 / parallel / 并行对照 | 同一维度上的选项或前后差异 | 共同基线，错峰变化，同屏读结果 | 标尺、条件、时间范围一致；不把两侧都塞满字 |
| G05 / reveal / 分层揭示 | 表象与内部、条件与转折 | 移开表层，暴露内部；上一层退出后下一层可读 | 不编造秘密；前后文字不互相穿透 |
| G06 / consequence / 动作与后果 | 文案明确支持的因果 | 条件触发动作，物体响应，结果留下 | 因果有原句依据；示意力度与数量不能冒充测量 |
| G07 / tracking / 追踪与锁定 | 观察、检查、筛选与证据 | 先看范围，追踪依据，再锁定目标或排除 | 框停在真实依据上；不能装饰性扫描或随意判定 |
| G08 / response / 人物现场回应 | 个人判断、经历、情绪与观点 | 真人先讲，重点字、图片或批注接话，再让位 | 保留真实表情；不得编造反应、替换嘴型或每句弹字 |

## 各机制如何落到十一类

画风、配色、材质、光影负责视觉身份；信息组织、造型、字体版式、物体动效、镜头、转场、节奏负责此次编排。前四类不是永不调整：换画幅或素材造成对比不足时可以做最小兼容修复，记录原因，不能借换编排顺带重做未授权部分。

### 空间漫游

信息组织先画只有必要节点的总图。造型给节点固定坐标与对象ID，处理过的状态保留。排版区分总图索引与局部正文，避免随世界缩放到不可读；必要时将索引留在屏幕层。主运动交给镜头，局部对象错后响应，不让两者竞争。转场通过走到相邻节点完成；节奏采用“定位—移动—到达—读图”，到站后必须停稳。每次回总图都核对已发生的损失、筛选或数量变化。

### 同物接力

信息组织先问同一对象为何要穿过每段。造型确定不会暗换身份的形状、编号或内容片段；材质随画风表现，不能让纸片无故像硬金属弹跳。排版把主文字绑定在真正可读的一面；翻转与缩小时旧字先退出。动作有预备、交付、接住的速度变化；镜头只为保持承接位置服务。交接在对象身份稳定的时刻发生，节奏为观众留“认出还是它”的时间。

### 拆解与组装

先列整体、部件、部件之间的关系；若只是并列建议，明确是解释性的结构隐喻。每个部件有独立轮廓和位置，不靠颜色单独区分。抽出一件时其他部件降权保留索引；局部标签避开回装路径。主动作是拆、停、处理、装，镜头景别帮助看清当前部件。转场延续实际部件，不用满屏闪白代替回装。最后重新组成的整体必须反映之前改变，不能复位清空过程。

### 并行对照

先定义共同问题和比较维度，再选等面积双栏、上下或前后位置。两侧文字层级和尺度一致；同一角色的颜色固定。动作错峰引导看第一侧，再看第二侧，结论同屏停稳。镜头尽量保持共同参考系，确需放大时保留另一侧缩略索引。转场由比较轴或共同对象交接，不交换左右意义。节奏为两侧总阅读量留窗，不能把一侧未说过的结果提前当事实出现。

### 分层揭示

记录每一层知道什么、何时揭开、揭开后观众改变哪个理解。造型必须存在可信的前后遮挡关系；纸页、遮罩、剖面等随母画风适配。正面字退出之后背面字才进入读窗；禁止透明叠字。动作必须暴露新的有用信息，镜头保持揭示边缘和被揭内容同在视野内。转折句触发揭开，揭开完成后停留，后段从暴露的对象继续。

### 动作与后果

先检查因果是否来自本次文案。给条件、触发、响应、结果分别登记，不把先后顺序自动当因果。对象动作有明确接触点、方向与结果；示意挤压或载荷只解释趋势，不能伪造实际数值。镜头在动作前留出后果空间；标题少而准，结果标签在动作稳定后出现。转场利用残留的状态，损失不无故恢复，减少负债不画成全部归零。强动作之后留安静的理解窗。

### 追踪与锁定

先列候选、判据、依据位置与筛选结果，禁止无证据评分。造型保留稳定的对象阵列；放大镜或框是注意力工具，不能遮掉被看的事实。每次追踪的起点、目标与停留都对应一句话。镜头只为看清依据放大，返回时对象仍可辨认。锁定后留下标记或移出被排除项，下一段从保留下来的集合开始，不能全体重置。

### 人物现场回应

真人承担完整表达。图文等语义关键字或语气落点出现后回应，具体延迟依原声判断，不机械复制案例中的5帧。图像不是表情替身；人物颜色、比例和真实表演保持。排版给脸、眼神和字幕预留路径，非重点图文及时退出。镜头从真人的表达强弱决定景别；小角窗全路径真圆等比。转场以讲述者的延续或其所指对象完成，结尾让位给本人收束。

## 与19套母画风组合

机制可用于19套母画风的设计入口，实际呈现须适配。编辑拼贴使用纸页承接；技术蓝图可以用构件、剖面和坐标；柔质立体用体积、形变和受力；水墨用笔迹、墨块、留白与显隐；单线手绘用路径生长和线条重组；写实极简尽量靠真实物件与清楚的构图。其他母画风从其正式配方读取材料、造型和光影规范，不把当前纸本底板贴到全部画风上。

选定配方后，逐项记录七个编排轴如何改变：空间关系、对象载体、文字层级、主动作、镜头任务、交接方式、读窗；另检查四个视觉身份轴是否仍成立。任何明确不适用的组合，都说明具体阻碍并提出最小调整，不以目录可选择冒称自动兼容。

## 指令与执行入口

用户可说：“使用网感口播插件，用我的素材，水墨画风，采用同物接力编排。”也可说：“画风保留，让智能体根据文案自由选择编排。”只改已有片时：“保留画风，编排换成并行对照，另存版本。”

```sh
node scripts/studio.mjs orchestrations
node scripts/studio.mjs orchestrations --id G02
node scripts/studio.mjs init --project /output/new-film --source /input/my.mp4 --recipe ink --orchestration relay
node scripts/studio.mjs init --project /output/auto-film --source /input/my.mp4 --recipe minimal --orchestration auto
node scripts/studio.mjs select-orchestration --project /output/auto-film --orchestration parallel --reason '本段对比同一条件下的两种选择，需要同屏保留共同基线'
node scripts/studio.mjs revise --from /output/old-film --out /output/new-version --orchestration reveal --request '保留画风，改为分层揭示'
node scripts/studio.mjs revise --from /output/old-film --out /output/rhythm-version --axes rhythm --request '只调整节奏，结果多停留一点'
```

`init`导入源片并创建待设计的十一份计划。`select-orchestration`只收束待定auto，不生成成片；已选编排使用`revise`另存版本。完成本片场景、状态、图片任务、帧函数实现后再`run`。换编排影响七类；只改一个模块，冻结其余计划、源片、原声、根字幕时间轴和编排身份。

八个批准案例以`source-bound-frame-functions-v1`保留真实代码，不假称已将所有动作改成通用参数。单独改节奏时需要把相关时间实现与节奏计划同步修改并验证，不能只改JSON冒称生效；原有symbolic-events-v1案例仍支持事件轨单改。两种合同不得混用。

## 复现、验证和清理

`reproduce --recipe editorial-print --orchestration spatial --source /input/approved-original.mp4 --project /output/reference`仅接受本轮自有原片的SHA。其余七类替换编排ID即可。正式包携带实现、十一份计划、绘图资源和认可证据；人物代理在本地从显式提供的原片生成，原声按EDL重建。源视频、批量成片与渲染缓存不随本轮提交到GitHub。

已认可范围：同一自有口播、统一基础视觉下的八条完整1080×1920视频，每条1100帧、30fps。保留它们的MP4哈希、读图路径检查、原声校验与拼版证据。正式集成另外验证指令、19×8组合选择合同、来源保护、模块范围和包内重建，不把这些检查等同于152条跨画风成片已验收。跨文案继续等待用户新自有素材。

制作时检查：人物颜色与比例、角落全路径真圆、字幕上移、文字路径不碰撞、每个动作有结果、对象终态延续、读窗足够、实际MP4原声完整、网页播放与Range206。结束仅清理本工程可重建的缓存与测试副本；保留用户原片、有效实现、已认可片和关键证据。
