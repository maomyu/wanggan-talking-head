# 共同制作规范

适用于正式插件的五个skill；用户后续明确指令优先。

1. 四个专家提示词保留完整正文。统筹负责交接，不用短骨架替代它们。任务是新片时先真实读懂源视频与音轨；内容、字幕、剪辑和图解都根据本次素材设计。
2. 真人保留源片颜色、皮肤、服装、比例与身份。不在真人上套网点、像素、手绘、水墨、黏土、线框、LUT或风格调色。风格只作用于背景、文字、图解、照片载体和窗框。
3. 人物进入左下或右下角时使用真实正圆：等宽高、overflow hidden、border-radius 50%、object-fit cover，整个缩放移动过程保持圆形。回到主画面且完成移动后才可恢复矩形。重新检查发顶、眼镜、下巴和路径中的遮挡。
4. 1080×1920的已认可字幕基线为top=1600、约60px、最多两行；其他画幅按比例重新构图并按实际字数检查。人物角落基准直径300，右x=716、左x=64、y=1255。这些是认可基准，遇到更长文字或不同人物可有理由调整，不能把字幕重新压到平台底部。
5. 使用一份最终时间轴。剪辑源映射、字幕、动效与声音从同一份真实时间依据生成；只有一个有声人声源，ASR边界只算候选。完整解码后按采样索引核对音频，避免快速seek AAC造成伪失配。
6. 正式画风库以style-library/catalog.json为准，区分用户认可、制作验证与尚未完成方向；只在取得相应证据后晋级。目录包含100个项目方向及其排版、动效、剪辑和声音配方，不把候选、名称或配方说成已完成视频，也不把这些方向当成互斥的行业标准。画风可继续扩充；组合按本片内容设计，已有案例通过不代表所有组合和新题材都全面验收。
7. 工作工程放插件外独立目录，单模块修改另存新版本并保留未选模块、原声、字幕语义与非剪辑时序。新增画风按docs/新增画风.md推进，保留旧条目与实际证据。
8. 本地制作、渲染、预览沿用用户授权持续完成。正式插件安装不等于授权发布到社交平台或向他人发送。独立代理仅在用户或适用指令授权时使用，不冒称盲评。
9. 预览页封面必须可点击在线播放，下载入口另标，支持进度和全屏；打开单片暂停其他播放器，关闭后释放人声。检查真实MP4及Range206，不能以HTML或概念样帧代替实际编码。

10. 声音按docs/声音协作.md交接，与原声共用时间轴。目录中的声音方案是建议，不代表自动生成了音乐；无新增声音任务时只保留原声。组合以内容和阅读窗口为依据，不能同时堆叠多套主画风或让动效改变人物风格。

当前库：100种已实现（20用户认可，80制作验证），本批100种全部完成。`styles --status implemented`查询可用实现，`--status approved`仅查询用户认可，`--status production`仅查询制作验证。`--example approved`为兼容沿用的固定素材复现命令，两类已实现模板均可使用，不表示都获用户逐条视觉认可。

11. 12套跨模块编排见[编排库与协作](编排库与协作.md)，选择依据是本片阅读任务、材料和真实人声窗口。各模块同时读取对应补充，原专家正文完整保留。新版100主搭配原生验证与12代表整片的证据分别记录，不借用旧100条整片验收；未实测自由组合仍为候选。
