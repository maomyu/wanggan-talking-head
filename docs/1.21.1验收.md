# 1.21.1 · 常用指令与使用指南

新增[使用指南](常用指令与使用指南.md)及统一入口的可复制指令库：3条整片示例、6条单模块示例，覆盖指定画风、智能体自由搭配、指定编排、字体排版、物体动效、转场、节奏、配色和自定义模块。页面可按任务切换，复制时附带自有口播、人物原色、角落圆窗、字幕上移、保留原声、独立工程及临时文件清理要求。

指南与页面使用同一份 prompts.json，通过 scripts/sync-usage-guide.mjs 更新指南。README、统一技能、旧使用说明和19套入口说明均加入导航。catalog-ui新导出的独立页面同步携带指南、指令库和保存指南入口。现有正式预览页就地更新，成片媒体不复制、不改写。

实际检查：

- 9条完整复制指令通过正式route命令：3条进入整片11类协作；6条只选对应轴，保留其他10类。修正“只使用自己的口播”误限制整片，以及“只改节奏：对比……”误扩大修改范围的关键词提示问题；路由仍是提示，智能体必须结合完整需求判断。
- Chromium实际点击9条复制按钮、共同要求与动态配方指令，剪贴板文本逐字一致。模拟拒绝剪贴板权限后，完整文字自动选中并提示手动复制，不虚报复制成功。
- 精密界面→技术蓝图→连续图解指令正常生成；切到只改物体动效时不夹带新的画风选择。
- 390px移动端无横向溢出；桌面及移动端实际截图查看。指南链接可打开。
- 现有19张画风卡正常加载，抽查原样片可在页面内播放到非零时间，1080×1920，无解码错误；本次未重新编码或重复宣称整片审片。
- 新建无媒体绑定的catalog-ui导出包含指南和可复制指令。依赖doctor、包结构与正文完整性检查通过；19套母画风、技术蓝图分支、220份计划和原四专家正文保持。

本次更新只改调用体验与相关范围识别，不增加画风或跨文案验证结论。未上传用户新素材，未修改视频制作配方。
