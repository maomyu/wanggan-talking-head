# 1.14.0 正式接入验收

正式加入12套跨模块编排，统一画风与编排的选择入口。四份专业SKILL.md全文及原哈希保持，原100画风条目和旧版整片证据保留。规则与使用见[编排库与协作](编排库与协作.md)。

## 本轮实际检查

- 100个主搭配从正式包逐条init/run重建：HTML、director、原片、原声PCM和EDL全部与各自研究绑定逐字节相同。工程位于插件外，不读取test目录运行。
- 正式入口重新完成杂志C02整片，以及仅字幕上移20像素的另存版，两条均为1080×1920、30fps、1100帧、36.6667秒，经过check、完整编码和解码核验。
- 两条新MP4原声相关性均约0.99998235，偏移0采样；局部版保护检查通过，其他模块、原片、字幕内容与时间、原声保持。
- 字幕局部修改不是只改方案文字：7个DOM状态测得top1580，从实际编码第567帧测得字幕线由y1600移至y1580，恰为20像素。人物无滤镜、等比正圆、单一视频源。
- 杂志A04＋卡片展列C05的新组合完成构建与HyperFrames检查；尚未将此新组合作为完整MP4验收。
- 新素材导入只记录A58＋C06选择，未注入样例字幕、图解或7段时间线；缺少真实设计时run拒绝输出。复现器遇到其他源哈希拒绝；非法编排不创建残留目录；字幕局部任务修改动效方案被保护检查拒绝。
- 实际预览页从按钮播放新MP4至36.6667秒结束；真实MP4的Range响应单独核验。作者查看实际编码拼版与代表帧，未使用独立盲评。

证据见[正式接入记录](../choreography-library/evidence/formal-integration/release-verification.json)、[100条重建绑定](../choreography-library/evidence/formal-integration/primary-rebuild.json)、[入口保护](../choreography-library/evidence/formal-integration/entry-guards.json)、[编码字幕位移](../choreography-library/evidence/formal-integration/encoded-caption-shift.json)。本机大视频和密集抽帧位于交付工程，未加入源码仓库。

## 验证范围

本轮承接的编排研究有100个主搭配、453张原生样帧、849个DOM状态、12个代表方案新版完整MP4；另有旧版100种画风的完整视频。正式接入重建100项并重新编码2条验证整片与局部路径，不能表述为再次渲染全部100条新版视频。

14项继承的严格复合像素寻址差异继续公开保留，详见[native-final](../choreography-library/evidence/native-final.json)。空间几何通过不等于所有像素确定，不以此次接入抹掉差异。100×12自由组合、新题材、其他画幅、新音乐/音效、源片重排和J/L剪辑没有在这轮全面验收。

安装使用本机personal插件源；依赖固定版本不升级。源码按用户授权同步私有仓库，缓存安装记录与提交身份以实际工具返回为准。
