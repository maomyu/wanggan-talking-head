# 协作合同 v1 · 正式插件

一个分类对应一个专业技能；分类下是可选择的设计标准；整片使用的是组合配方。标准库不限制以后新增，数量不是目标。“标准”在此指可复用设计语言，质量验收另列。

十一类不是十一个必须依次调用的远程程序。代理依据任务读取专业指令，生成和修改实际工程；现有解析器只执行结构检查、场景计划检查和修改影响分析，不声称一键自动渲染。

## 字段与归属

| 分类 | 唯一维护 | 交接重点 |
|---|---|---|
| 主画风 | 语言身份、参考原则、漂移规则 | 让各场像同一片 |
| 配色 | 角色色、强调语义、对比配对 | 不处理真人调色 |
| 材质 | surface纹理、边缘、反射外观 | 纹理身份与尺度 |
| 造型 | object几何、正反面、部件、锚点 | 框和纸页实体只建一次 |
| 物体动效 | 对象状态变化、路径、落定 | 动词、结果、全路径避让 |
| 镜头 | 观察点、取景、焦点、景别 | 不重复修改对象位置 |
| 转场 | 两端交接、覆盖帧、共享锚点 | 退出字和新字交接 |
| 字体版式 | 字体角色、字形边界、阅读区 | 人物、字幕与图像共同构图 |
| 光影质感 | 光区、投影、合成强度/顺序 | 引用材质纹理，不重复制造 |
| 信息组织 | 主张、关系、素材任务 | 并列不画因果，引文不编造 |
| 节奏 | 锚点、读窗、密度、事件表 | 真实原声与完整显现 |

完整声音、源片删改/EDL、源→输出映射、编码和在线播放由统筹管理，是制作基础。未来有独立声音需求可另扩展专业技能；本轮不擅自变成第十二个必选审美维度。

## 共享对象和时间

- objectId：同一对象跨镜保持身份。复制实例另有instanceId，不据此暗改真实数量。
- surfaceId：材质与光影共同引用一个表面，纸页正反面分别定义。
- sentenceId/claimId：文字、动作、图片都能追溯到原句或明确示意。ASR不是已校正真值。
- textId：正文、字幕、标签、批注、来源有明确身份和角色。
- frame：统一输出帧；区间采用[startFrame,endFrame)半开区间。最后一帧是endFrame-1。音频按采样索引核对。

当语义相互独立时可以分模块制作；共享约束与最终时间轴不能各自维护副本。单人代理也能执行全部技能，不默认派十一名代理。

## 保留的用户原则

源片优先用户本次明确上传或已确认自有口播。人物保留源色、皮肤、服装和比例；背景、物件、图解、文字可变风格。角落窗等宽高、真实圆裁切、缩放路径全程等比。1080×1920字幕top1600、约60px、最多两行是认可参考，其他内容/画幅据真实字形重排，不退回底边。人声只有一路有声源，不因动画重启人物视频。

字形不被挡是跨模块合同，不只是字体模块职责。包括半透明退出的旧字、阴影、遮罩、运动物件和圆窗。检查初态、峰值、结果态与交接帧。读窗从完整可读起计，不把移动存在算阅读。素材可保留有效旧实现，但新文案必须重新解释，不沿用旧财经分镜作为通用答案。

## 修改影响

plan-change的rewrite只列真正改写的维度；revalidate列兼容复核对象，并非要求它们全部重做。信息或EDL改变可能影响所有时间事件；改色通常仅需对比与合成检查。依赖不是无限递归广播，不因为模块互有关联就每次重做全片。

原始素材、原声语义、未选模块与旧版本保持。跨模块兼容修复写清触发、字段和帧。原有工程、有效素材与旧100项实现保留，分类只通过兼容映射改变选择入口。

1.20.0起人物主导、连续图解在registry/orchestrations.json单独登记，与画风分开选择；其实际完整验证为写实极简同源三版。单独节奏修改保护其他十类计划、原片、原声、字幕时间与编排；方法及复现边界见[编排选择与局部节奏](编排选择与局部节奏.md)。
