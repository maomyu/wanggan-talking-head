# 网感口播使用指南

上传自己的口播视频，或提供可访问的本地文件路径，然后说“使用网感口播插件……”即可。统一入口是 talking-head-video，由它协调11类技能，不需要逐个调用。

## 怎么开始

1. 新视频：上传你自己的口播，或给出本地路径。指定画风，或让智能体自由搭配。
2. 改已有视频：接着原制作对话提出需求，并指明版本。新开对话时提供可编辑工程路径；只有导出的MP4无法准确保留各模块的编辑信息，需要先恢复工程。
3. 在下面选一条指令，将方括号中的内容换成实际素材、工程或需求。明确的后续指令优先于默认要求。

统一入口页面的“常用指令”可按整片制作、单模块修改切换；每条复制时自动附带下面的共同要求。“选配方”区域可按当前母画风、分支、组件和编排生成指令。页面用于选择与复制；将指令发给智能体后，由它完成设计、制作与验证。

## 共同要求

这些是当前已确认的默认要求。新开对话时可附上，页面复制会自动包含。

```text
共同要求：只使用我自己的口播，保留原声和原意；人物保持原色，缩到角落时全程使用圆形窗口，字幕保持上移并检查遮挡。动作、图片和转场要与本次文案配合，保持前后连续性。工程放在插件外独立目录，修改另存新版本，交付完整视频和在线播放预览。完成后清理可再生成的临时文件，保留源素材、工程、成片和关键检查记录。
```

## 常用指令

### 1. 指定画风，制作整片

已经选好视觉方向；将写实极简替换成你喜欢的母画风。

```text
使用网感口播插件，把[我上传的口播视频或自有素材本地路径]制作成完整视频，采用「写实极简」配方。根据实际口播设计排版、图片、动作和转场，让前后的对象和解释连续起来。
```

### 2. 让智能体自由搭配

不预设画风，由实际内容决定合适的视觉语言和讲述方式。

```text
使用网感口播插件，根据[我上传的口播视频或自有素材本地路径]的主题、语气和信息结构，自主选择合适的母画风、分支、组件和编排方式。简要说明选择理由后直接制作。动作、图片和转场从文案中的因果、对比、转折和强调出发设计，不要机械套用旧视频，也不必为了丰富而增加不需要的组件。
```

### 3. 同时指定画风和编排

技术蓝图属于精密界面分支；画风和编排可分别选择。

```text
使用网感口播插件，把[我上传的口播视频或自有素材本地路径]制作成完整视频。采用「精密界面」母画风下的「技术蓝图」分支，使用「连续图解」编排。让同一组对象随着口播持续发生变化，用动作解释原因、过程和结果；根据实际文案安排，没有因果的内容不要强画成因果。
```

### 4. 只修改字体和排版

处理标题主次、图解标签、字幕位置和文字遮挡。

```text
使用网感口播插件，基于[工程路径或现有版本]，只修改字体版式：标题更突出，图解标签更清楚，避免文字被人物、图片或字幕遮挡。保持现有画风、配色、动作、镜头、转场和原声，另存一个版本供我在线播放对比。
```

### 5. 只加强物体动效

针对某句话设计有解释作用的动作，保持其他模块。

```text
使用网感口播插件，基于[工程路径或现有版本]，只调整物体动效。重点修改[具体时间段或句子]，让对象的动作直接解释这句话，并呈现清楚的变化结果。减少没有解释作用的来回移动，保留其他模块，另存在线播放对比版。
```

### 6. 只修改转场

解决前后衔接，不顺带重剪原声或重做整片。

```text
使用网感口播插件，基于[工程路径或现有版本]，只优化转场。优先利用前后段落共有的物体、形状或空间位置完成衔接，让上一段的结果成为下一段的起点。保留段落顺序、原声、画风和主要构图，另存在线播放对比版。
```

### 7. 只调整节奏

调整强调、读图停留和动作密度，不加速原声。

```text
使用网感口播插件，基于[工程路径或现有版本]，只调整视觉节奏：[对比结果多停留一点／重点更早出现／减少同时发生的动作／结尾留出回味]。保持原声语速、时长和内容，不改变画风与编排主线，输出调整前后的在线播放对比。
```

### 8. 只修改配色

修改背景、文字和图解的颜色，真人颜色保持。

```text
使用网感口播插件，基于[工程路径或现有版本]，只把配色调整为[目标配色，例如冷灰蓝、米白和少量朱红]。人物保持原色，保留现有材质、字体版式、对象、动作、镜头、转场、节奏、字幕与原声；检查文字对比度，另存在线播放对比版。
```

### 9. 其他单模块修改

适用于材质、造型、镜头、光影、信息组织等具体调整。

```text
使用网感口播插件，基于[工程路径或现有版本]，只修改[模块名称]，目标是[具体效果，可附时间段或原句]。其余部分保持，另存新版供在线播放对比；若确实需要关联调整，说明原因和范围，并保持最小变化。
```

## 画风和编排怎么选

画风决定视觉语言，编排决定观众如何跟随讲述，两者分开选择。

| 编排 | 适合内容 | 调用说法 |
|---|---|---|
| 人物主导 | 观点、个人经历、情绪和信任感 | “采用人物主导编排” |
| 连续图解 | 因果、对比、机制、数量或条件变化 | “采用连续图解编排” |
| 智能选择 | 不预设结构，由真实内容决定主次 | “由智能体按内容选择编排” |

目前有19套母画风配方，技术蓝图是精密界面的分支。母画风、分支和组件分别管理；不必每次都指定分支和组件。可在统一入口查看全部母画风及完整协作计划。

## 单模块修改的边界

可单独指定：主画风、配色、材质、造型、物体动效、镜头、转场、字体版式、光影、信息组织、节奏。说清“只改什么、希望怎样、保留什么”，有时间段或原句时一起提供。复查关联模块不等于重写它们；必要兼容修复说明原因并保持最小范围。

“只改节奏”默认调整视觉事件和阅读窗口，保留原声语速与内容。源片删减或改变句子顺序属于剪辑范围，需要在需求中明确。未指定声音任务时保留原声，不自动增加音乐或音效。

## 当前验证范围

19套母画风和技术蓝图分支已有同源完整视频与认可实现；节奏、配色已有单模块完整视频实测。其他模块和组合依实际修改内容检查，不将目录登记等同于任意组合都已验收。跨文案仍待你提供新的自有口播再实测；新素材需要重新理解文案、设计对象动作和转场，不能套旧财经分镜。

工程和成片保存到插件外独立目录，默认不将你的源视频与成片上传GitHub。清理只针对可再生成的临时文件。
