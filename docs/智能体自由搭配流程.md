# 智能体自由搭配：从文案到可见动作

本流程由用户认可的三条完整视频正式收录。画风决定视觉语言，编排决定理解路径；二者共同约束十一类设计，但不替代真实文案分析。19套母画风、8类编排保持原数，三组已验证组合单独登记于registry/combinations.json。分支和组件仍独立管理，不把搭配结果再算作一种母画风。

## 一、把任务读成观众需要理解的变化

先遵守[新素材制作流程](新素材制作流程.md)、[素材与原声](素材与原声.md)与[共同制作规范](共同制作规范.md)。使用当前用户明确选定的自有口播，校正否定、条件、数字、转折与专名；没有第二条自有素材，就如实使用现有素材，不借用别人的口播替测。

从原句逐段写出：说的是什么、原句是什么关系、观众在哪里容易误解、画面能补足什么。建议并列就是并列，不能为了动画流畅强行排成因果。听到“减少”不能画成“全部清零”；听到“风险”不能自动造出收益率或概率。数量用于示意时明确标注，并保持前后状态一致。没有来源的购买记录、资产数值和财务结论不添加。

每段至少落为一条语义事件：sentenceId、关系、理解任务、objectId、初态、主动作、终态、阅读窗口、向下一段交接的对象或位置。只写“放大图片、加特效”不能通过；把名词换成另一张图片也不能替代解释。

## 二、先推导动作，再选视觉语言和主编排

1. 找到贯穿全片的理解任务：观察和核查、选择和筛除、结构和重组、动作和结果，或人物现场回应。不是每句话都要强绑定同一物件，但接续关系必须清楚。
2. 写一个不用特效名称也能理解的动作句。例如“把不必要的加购划出去并保留结果”“观察框移到收益承诺，翻出背面风险”“负担落到承重台上，使平台下沉；卸下一部分后回升”。动作终态决定下一场的起点。
3. 选择一个主编排。读[八类编排机制](八类编排机制.md)，比较其适用条件和失效方式。同物接力需要身份延续；追踪与锁定需要稳定观察坐标；动作与后果需要可见接触和结果，不能把并列建议伪装成物理因果。其他五类同样依据内容选择。
4. 从19套母画风选择能支持这些动作的语言。水墨可以用笔势、留白和留印承接判断；精密界面可以用观察矩阵与检查状态；柔质立体可以用模型接触与受力比喻。这些是本案例适配理由，不是以后所有财经文案的默认三选一。
5. 只有本片需要时才选分支或组件。纸张、胶片框、网格、图标各自承担任务；不能为了数量给每场硬加组件。用户指定维度优先，在其边界内选择其他维度。

把选择写入selection-rationale.md：原句关系与事实来源、候选方向、最终母画风/分支/组件/主编排、每项理由、哪些旧实现可以复用、哪些必须重做、风险短测位置。不必把整张选择表交给用户逐条批准；已经授权制作就继续做，简要说明判断即可。

## 三、需要多版时，区别落在组织方式上

三版比较保持素材、原声、原意和画幅一致，让排版、动作、镜头和转场产生可辨识区别。不要只交换配色、背景图或标题字体。至少比较以下四项的关键时刻：信息先后与视线路径、对象如何发生变化、镜头观察的空间、前后段落如何接住。

| 已认可组合 | 信息和构图 | 动作与连续性 | 镜头与交接 |
|---|---|---|---|
| K01 水墨写意 × 同物接力 | 右侧竖题、左侧内容场、大留白 | 同一判断印沿弧线移动，筛除、圈护、移开负担；墨迹留下结果 | 固定纸面为主，同一墨圈与朱印连续承接 |
| K02 精密界面 × 追踪与锁定 | 章节索引、固定证据矩阵、结果条 | 一个观察框逐项锁定，落定后才更新核查结果 | 保持对照坐标，局部检查收益说法背面，已核查状态保留 |
| K03 柔质立体 × 动作与后果 | 中央立体承重台、短大标题、清楚的外层标签 | 落物、下压、保护、翻面、卸载都有可见结果 | 真实三维斜视与有限横移，同一舞台改换任务；标签留足正面读窗 |

这三版的核心复用单位是解释机制、对象状态和交接规则。朱印、矩阵、承重台、财经图片、6→4或3→1等示意数量及1100帧时间点都属于原案例，不是新素材默认内容。新主题可保留同物接力的原则，却必须换成本片有意义的贯穿对象。

## 四、十一类协作落到同一工程

| 类别 | 本阶段必须交付 | 与其他模块的约束 |
|---|---|---|
| 主画风 | 身份规则、可变项、禁止项 | 约束材质、造型和字体；不处理人物肤色 |
| 配色 | 背景、主体、强调、文字的颜色角色 | 保证阅读对比，人物层不套调色 |
| 材质 | 表面、边缘、纹理和响应 | 必须支持对象行为，纹理不能吞字 |
| 造型 | 对象ID、几何、表面、图片任务和遮罩 | 图片按对象拆分；不每场重建全部对象 |
| 物体动效 | 初态、主动作、可见结果、跟随动作 | 结果持续存在；与原声锚点和镜头共享时间 |
| 镜头 | 景别、观察范围、运动动机、落定读窗 | 镜头运动不能把人物或标签带进文字区 |
| 转场 | 交出对象/位置、接住状态、遮挡先后 | 上段终态成为下段起点，禁止无故重置 |
| 字体版式 | 人物、标题、图解、字幕的阅读层级 | 全路径而非关键帧检查；必要时主动让位 |
| 光影 | 光照、阴影、纹理收束与合成顺序 | 风格仅施于解释场景；原色人物独立合成 |
| 信息组织 | 原句关系、理解任务、事实和图像绑定 | 不让比喻暗改事实，不把并列画成因果 |
| 节奏 | 原声锚点、动作起落、停留和退场 | 视觉强弱跟随口播，字幕与原声时间不随意改 |

四份完整专家方法继续保留全文，十一类各自完整技能照常调用。计划集中到plans/内，scene-plan.json负责语义交接，timing.json负责真实声音与字幕。状态、人物、镜头和标签共用确定性帧函数；新节奏方法优先事件引用。继承旧帧函数时明确写出时序所有权，不声称可无成本任意重排。

图片不足时先判断缺的是对象、局部细节、初末状态还是关系。优先拆分、裁切或重建有效素材；需要生图时针对明确任务生成，固定身份和状态。不用整张相关图片来回平移充当解释。不把示意图冒充原始财务证据。

## 五、调用方式与实际边界

自然语言直接交给 talking-head-video；需要多版就明确“三组明显不同的完整视频，同页对比”。代理按本流程完成选择、11类设计、代码和成片，不停在JSON或建议阶段。

```sh
node scripts/studio.mjs combinations
node scripts/studio.mjs inspect --combination ink-relay
# 新素材：只继承组合方向，不注入旧财经分镜。
node scripts/studio.mjs init --project 新工程 --source 自有视频 --combination ink-relay
# 自由选择：代理先判断母画风，再记录主编排；不是随机抽签。
node scripts/studio.mjs init --project 新工程 --source 自有视频 --recipe ink --orchestration auto
node scripts/studio.mjs select-orchestration --project 新工程 --orchestration relay --reason 本片语义与选择依据
# 仅明确同源复现；需要原始完整原片，哈希不符会拒绝。
node scripts/studio.mjs reproduce --project 新工程 --source 原案例完整原片 --combination ink-relay
node scripts/studio.mjs run --project 新工程 --until build
```

K02使用precision-tracking，K03使用clay-consequence；支持K编号与登记全名。组合与显式配方或编排冲突时拒绝，避免静默覆盖。init创建的是待设计工程，必须完成实际11类计划和本片实现；auto未决不能构建。reproduce只用于明确的原案例，原声从源片EDL重建，不把旧成片复制出来冒充新渲染。

需要只改模块，继续使用revise并给出轴名、实际修改要求、保留内容。编排不变时冻结它；只改节奏默认保留其他十类决定、原声和根字幕时间轴。具体计划与实现不解耦的旧案例，需要代理改动相关视觉时间函数并重新检查，不能假装单改JSON必然生效。换编排联动七类讲述模块，保留未选的四类视觉身份；必要跨模块兼容修复记录原因和最小范围。

## 六、检查实际视频与交付

最难的交接、密集信息和3D背面字先做短测。可复用已实测机制，不机械重复无变化的完整编码。新制作仍需要实际完整MP4验证；迁移已认可实现则以旧视频哈希、独立构建和画面一致性证明迁移范围，不能冒称新渲染。

- 语义：原句与图片/动作逐项对应；数量终态不恢复，减少不变清零；并列、转折、条件和因果不混淆。
- 动作：有准备、主变化、结果和读窗；转场前后同一对象的身份、数量、位置或目标连续；不只移动相关图片。
- 人物：无风格滤镜、肤色改造或全片LUT；角落及缩放路径均等比真圆。用实际编码帧检查，不能只读CSS。
- 阅读：字幕上移，当前1080×1920样例字幕顶在1600附近；新构图按平台安全区与字形高度适配，不套百分比盲猜。全路径检查人与字、字与图、旧字残影和3D背面标签。
- 音画：检查实际MP4帧数、尺寸、fps、原声连续与时差；原声未剪不声称精剪。默认不新增音乐或音效；需要声音再按声音协作方法做。
- 播放：在线直播放、Range206、手机无横向溢出、同播最多一路声音、关闭大图释放播放器。实际完整播放与抽帧记录分开，不把自动播放检查称为主观听审。

按现行规则默认作者自查。明确要求独立评审时才另派评审。记录真实方法、问题与改动，不把“无报错”当审美通过。完成后保留原素材、工程、最终片、可播放页和关键证据；仅清理本轮可再生成的密集帧、代理副本和缓存。

当前验证为同一条用户自有36.7秒素材上的三组完整片。19×8是可选设计空间，不是152条已实测成片；跨文案仍等待新的自有素材。其他组合由本流程实际适配与验证，不能因为这三组通过就宣布全部自动适配已验收。
