# 1.21.0 · 十九套母画风统一生产入口

2026-10-24用户认可研究版并授权正式并入、更新本机插件及同步GitHub私有仓库。

本版正式收录19套母画风与技术蓝图分支，共20套可调用的完整配方、220份实际专业计划。38个分支方向、43项组件来源、85项专业标准分开管理；原四份专家正文哈希、旧100项资源、旧七套案例和两套编排保留。七套旧配方定义另存历史版本，新默认源码位于examples/production-recipes，不依赖test目录。

统一入口增加catalog、inspect、母画风/分支/组件选择、reference别名、配色补丁、范围检查及可导出的可视入口。素材与工程保存在插件外，新源初始化继续等待本片专业设计；显式同源复现才加载源绑定案例。

正式入口集成通过27项选择与保护检查、全部20套实现的实际构建。20套生成的HTML（去除检查器自动标记）、画面参数、动效、时间轴、EDL及原声WAV均与已认可案例一致。配色修改版参数与已认可改版一致，未选模块、源声音与实现受到保护。证据见[正式入口集成报告](../evidence/production-recipes/integration-1.21.0.json)。本轮复用已认可MP4，不冒称又编码20条新视频。

配色研究片此前完成1100帧几何与文字路径对比及实际完整编码；声音偏移0采样，人物源色/圆窗/字幕边界沿用已认可检查。新导出的正式页面不依赖研究路径，使用相同哈希成片；21个媒体Range请求通过。浏览器实际选择、分支调用与原生播放另留本机交付记录。

跨文案按用户安排延期，直到用户提供另一条自有素材；本轮不借用他人的口播补测。任意分支、组件和编排组合不视为全面验证。单模块的具体创意修改仍逐次执行相应检查，不把配色实测扩大为所有轴都完整视频验收。

发布源码包含实现、生成的画面素材、配方、完整技能、依赖锁及证据；本次用户原片、原声、成片、依赖目录和临时工程不新增到Git。完成后删除本轮验证副本与缓存，保留原案例和独立正式入口。
