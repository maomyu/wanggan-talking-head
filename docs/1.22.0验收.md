# 1.22.0 · 八类编排正式接入

用户已明确认可八条完整视频，授权并入正式插件并同步私有仓库。本版保留19套母画风、技术蓝图分支、分支/组件分层管理、11类完整协作及原四份专家正文。

## 本次变化

- 正式登记空间漫游、同物接力、拆解与组装、并行对照、分层揭示、动作与后果、追踪与锁定、人物现场回应。人物主导与连续图解作为兼容方向保留。八种机制不增加母画风数量。
- 每类携带完整实际实现、11份专业计划、原视频哈希、认可记录和拼版；新增88份计划。完整机制方法见[八类编排机制](八类编排机制.md)，不是缩短的特效骨架。
- CLI支持ID、G01–G08和中文名选择；auto要求智能体先记录基于文案的选择理由，未决不能进入构建。选择不伪装为已完成创意设计。
- 换编排联动七类讲述模块；单独改节奏或其他模块继续保护其余计划、编排、源片、原声和字幕时间轴。
- 统一页面分开选择画风、分支、组件与编排，包含11条可复制指令。可按已认可MP4哈希绑定八条在线样片。

## 实际核验

1. 正式CLI独立重建八个工程，画面源码、配置、图片和字体保持，原声WAV与认可版本一致。重建人物代理只裁切缩放，不调色、不风格化；八个代理哈希相同，另核对实际人像帧。
2. 检查8×1100个作者帧的文字/人物路径与上移字幕；检查80个关键画布状态及实际像素。状态逐项相同；半透明边缘有浏览器舍入差异时按严格像素容差记录，没有将PNG编码字节差异误判为画面改版。详见[集成记录](../evidence/releases/1.22.0/integration.json)。
3. 19×8选择合同通过，未向新素材注入旧财经分镜；auto未决、无理由选择、错源SHA、冒称跨画风案例复现均被拦截。
4. 局部节奏保留其余十份计划，篡改配色会被拒绝；换编排只开放七类并保留四类视觉身份。原有两套编排重新构建，画面输入与原声匹配认可版本。
5. 页面实际检查19张母画风卡、8张编排卡、8机制+2兼容方向+auto、剪贴板内容、单模块指令、1080P在线播放和跳转；8个视频URL均支持Range206，390px手机页面无横向溢出。
6. 固定依赖doctor、19套配方审计、四份完整专家正文哈希和包清单检查。保留原有效素材、实现和新认可视频；本轮不上传用户原片与批量成片。

本轮没有重新编码八条完整成片，沿用用户刚认可且有哈希绑定的最终MP4；正式接入另做实际构建、状态和像素核验。未宣称152条跨画风组合全部成片验收；跨文案继续等待新的自有素材。没有新增配乐、音效或他人口播。

## 交付与清理

正式源码与包内相对引用不依赖test。在线入口工程在插件外独立保存，保留19套母画风与八类编排的已认可本地视频。结束清理本轮重建代理、临时工程副本和差异诊断图，保留集成报告与网页检查证据；不删用户原片、历史有效工程或认可样片。
