# 当前可用范围

1.18.0正式收录十一类专业技能与协作统筹，原四份完整专家正文继续按原哈希保留。母画风、分支、组件分别登记，旧100项ID、有效素材、模板和历史证据保留。四套认可配方带实际专业计划、源特定帧函数与原完整成片哈希。

统一入口可以列出分类、组合配方、检查结构依赖和场景计划、为新素材建立工程、分析局部修改影响、保护未改内容、构建、渲染和核验实际视频。创意理解与制作由代理按完整技能完成，解析器不会替代导演判断或自动理解所有文案。

85项是专业设计标准，不是85个普适执行组件。43项组件来源保留旧完整模板与研究子集，未宣称已经任意组合适配；其状态和边界逐项登记。四套原案例证明该源片上的协调执行，不能泛化为任意内容、任意组合或每种母画风都完成了新一轮验证。

源片默认用户自己的真人口播与原声。原片归属来自用户会话确认，路径或SHA不证明版权。人物源色、角落真圆与上移字幕为共享保护；多片同页可用原生播放器对照，浏览器负载下不声称逐帧同步。抽帧、程序音频核对和真实1倍速看听分别记录。

固定运行环境、字体与本地素材继续共用。仓库不包含新用户原片、最终MP4和依赖目录；原素材仍在原项目，离开本机需自行提供明确选定源片。迁移验收见evidence/migration-1.18.0.json。
