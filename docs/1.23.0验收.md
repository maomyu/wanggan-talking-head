# 1.23.0 · 三组组合与自由搭配正式接入

用户明确认可水墨写意×同物接力、精密界面×追踪与锁定、柔质立体×动作与后果三条完整视频，并授权正式并入及同步私有仓库。

## 正式能力

三组完整实现与33份实际专业计划以独立组合登记收录，保留原来的19套母画风、技术蓝图分支、8类具体编排、2个兼容方向、11类技能、原四专家全文及旧有效素材实现。母画风、分支、组件与编排仍分开管理。

[智能体自由搭配流程](智能体自由搭配流程.md)完整说明：原句关系→动作与结果→图片任务→选择母画风和主编排→11类协作→连续交接→实际视频检查。多版须在排版、动作、镜头与转场上形成区别，不能只换背景和颜色。已授权制作不增加逐项审批。

`combinations`和`inspect --combination`查询；`init --combination`创建新内容待设计工程，继承方向而不注入旧财经文案。自由选择保持`--orchestration auto`及基于文案的理由记录；`reproduce --combination`只接受认可原案例完整源片SHA。局部修改继续用revise，保留未选模块和编排。新入口支持三组原片在线播放、同播单路原声、复制组合指令与自由搭配三版指令。

## 实际验证

- 三组通过正式CLI从原片独立建立工程并构建，核心代码、配置、图片、原声、原字幕、语义分镜与认可版本一致。新工程不复制旧最终MP4作为新结果。
- 3300帧作者状态路径检查：人物与文字没有记录内碰撞，字幕保持上移，反向跳转可重现相同状态。30个关键状态与40个画布实际像素比较通过，包含柔质立体真实Three.js画布；浏览器透明边缘舍入按严格容差核验。
- 重建人物代理只有无调色裁切和缩放，三份代理一致。与认可代理在第130、657、925帧解码RGB逐像素相同；编码文件字节差异不当作风格改变。
- 三个组合init均保持11类待设计，不带旧scene-plan；错源复现、配方/编排冲突、auto无理由未决被拦截。节奏局部修改保留编排与其余十类计划，改写冻结配色会被拒绝。
- 正式页面检查19母画风、8编排、3组合及11个选择项；复制指令、组合选择、局部修改范围、三路1080P播放、最多一路原声、暂停/归零、Range206、流程文档与390px手机无横向溢出。
- 固定依赖、包结构、Markdown引用、组合实现哈希和四份完整专家原哈希检查。

本次沿用用户刚认可且已绑定SHA的三条1100帧、1080×1920、30fps完整MP4，另做正式迁移构建与画面核验，没有无变化重复编码。原片、已认可视频和有效工程保留。历史实际MP4、原色人像、音频与完整播放检查见evidence/releases/1.23.0中的approved记录，迁移证据另存integration与entry记录。

这三组只在同一条自有36.7秒素材上通过，不代表19×8全部组合成片验证。跨文案等新的自有素材。审核为作者检查与实际工具核验，不冒充独立评审或完整主观听审。默认保留原声，没有新增音乐、音效或他人口播。

## 交付及清理

正式包独立包含实现、计划、素材和流程，执行代码不依赖test目录。本地在线播放入口独立保存，绑定已认可视频；GitHub仅同步源码、可复用资源与关键证据，不新增上传用户原片或批量成片。

清理限定本轮迁移重建工程、重复代理、临时错误样例和检查过程文件；保留最终正式入口、原认可研究片、关键报告及必要证据。逻辑字节统计与可用物理空间区分记录。
