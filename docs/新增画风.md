# 新增画风

用户随时可以用自然语言提出新增风格。先读完整画风skill及共同制作规范，理解材料、字体、构图、对象和运动语汇；画风改动不得改变人物原色或角落圆窗。

在插件外新项目研究，先样帧，再做含真实人物与图解切换的视频。让排版、动效和剪辑模块完成真实交接，检查实际成片。用户确认后在style-library/catalog.json将现有候选按原key和编号晋级（同时从extensions移入styles并更新数量），全新方向则追加唯一key和编号，登记模板、真实预览、视频哈希和验证范围；保留所有旧条目。候选不能冒称已认可，概念图不能登记为完成视频。

实现参考放style-library/templates/<key>，预览放previews，证据放evidence。模板中的财经案例仅为已认可参考，处理新内容须重新设计真实文字和图解。升级插件版本，重建manifest，跑doctor、skill校验和影响范围的播放/渲染检查，再通过Codex的插件安装命令更新。不要直接改安装缓存或添加第二套孤立skill。

当前100种落地目标已获用户授权：新增方向经实际整片、程序检查与作者审看后，可按verified-video（制作验证）纳入正式实现，无需逐批新增确认。只有用户实际认可过的方向才标approved-video；这两类均可用，但证据与数量分开记录。
