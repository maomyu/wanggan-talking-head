# 全部视频案例总览

正式选择入口顶部和导航新增“全部视频案例”，地址为入口下的review/samples.html。它把现有完整视频放在同一个页面，可按分类筛选、搜索、卡片内播放、放大观看与下载；播放筛选结果默认为静音，听原声只保留一路。切换分类暂停并释放旧播放器；关闭大图释放媒体。

本机日常总览目前展示35个案例入口：

| 分类 | 数量 |
|---|---:|
| 母画风 | 19 |
| 已实现分支：技术蓝图 | 1 |
| 八类具体编排 | 8 |
| 人物主导、连续图解 | 2 |
| 已认可自由搭配组合 | 3 |
| 单模块修改：配色、节奏 | 2 |

当前案例合计35条。历史100项已从日常页面和筛选项中移除；原素材、有效实现及既有 `registry/gallery-extra.json` 中的历史绑定继续归档保留。刷新入口也不会把它们重新加入日常展示。本次没有删除历史原片或重新渲染视频。

当前案例均来自用户此前上传的自有口播；不展示第三方研究口播、渲染短测、失败输出或同一文件的多份拷贝。卡片、放大观看和听原声均使用已有完整视频，批量播放默认静音。浏览器同播用于比较，不保证跨播放器逐帧同步。封面和路径来自明确的本地绑定，不递归暴露整个磁盘。

## 维护入口

`catalog-ui --project 新目录`自动生成已绑定样片的总览。对已有正式入口增加样片，可运行：

```sh
node scripts/studio.mjs gallery-ui --project 现有正式入口目录 --extra-media-map 本地案例JSON
```

不传extra-media-map时保留已有扩展绑定并刷新页面。`history` 绑定仅供兼容归档，不加入 `samples.json` 的可见条目；当前样片使用 `attention` 或 `module`，其他类别从正式注册表读取。新增清单为数组，每项包含唯一id、name、kind（attention/module/history）、video、poster、sha256和实际说明detail；可选preview及previewSha256、sourceSha256、status与duration。MP4和可选预览均核对SHA后复制成独立本地文件；已有目标不同则拒绝覆盖，支持文件系统克隆。母画风、分支、机制、组合及配色案例从当前正式入口的绑定读取。

视频留在插件外的入口工程内，插件和GitHub只保留生成器、页面与必要验证证据。旧有制作实现及专业技能不改。新增视频必须先确认来源、最终文件和验证状态，再显式绑定。
