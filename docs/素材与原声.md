# 素材与原声

用户当前明确要求：后续制作继续使用自己的口播，不用别人的口播替代。这里约定的是本插件的默认素材选择；用户以后明确指定新的素材时，以当次要求为准。

## 怎样选择制作源

先用当前请求明确提供或指定的自有视频、文案与原声。用户说“继续用我自己的”“用之前的素材”时，查找已确认自有素材的来源记录，并核对实际文件、人物与哈希，不把最近打开的研究页面当作当前制作源。当前源绑定的记录见[自有素材记录](../research/semantic-transfer-20261020/evidence/user-source.json)，原文件保存在用户本地，不随本次源码同步上传。

没有新的指定时，可以沿用这份已确认素材；若文件不可用或有多个无法判断的候选，请用户提供或明确选择。不要为了继续制作而自动搜索、下载另一个人的口播。路径、标题、公开可下载和历史一次测试授权，都不能代替用户当前对生产素材的选择。

新工程保留原文件标识、哈希、时长、帧率和原声来源。存在裁切、代理或重编码时保留与原片的对应关系，确认是同一人物、同一口播；不能只核对文件名。CLI明确接收输入并记录哈希，所有权依据由代理从用户上下文核对，不能把“导入成功”写成“已确认自有”。

## 研究与制作的关系

第三方参考可以用于理解动作、转场、素材配合或其他用户指定的研究目的。研究中出现的人物、声音和文案不成为后续默认素材；本轮62.7秒测试只作为历史迁移证据保存。用户认可的是根据新稿重新设计的方法，不代表要求之后继续使用这个讲述者。

历史案例、100种画风模板与显式复现命令保留，便于对照和恢复；只有用户明确要求复现历史案例时才走该入口。用户的自有口播制作走新素材设计入口，不因既有模板漂亮而换成样例人物或台词。

用于解释的照片、图解、物品生成图与口播人物分工不同。按本片语义选择并说明证据、环境、对象、对比或比喻任务，必要的示意标注保留。制作仍保留用户原声；未提出新的声音任务时，不换配音、不克隆第三方声音。

## 固定保留的视觉约定

人物保留原色、肤色、服装、身份与比例。进入左右下角时，移动和缩放全程使用真正的正圆窗口。1080×1920字幕继承top1600、约60px、最多两行的认可基线，并按真实字数和平台遮挡复查；不因换素材把字幕压回底部。具体要求见[共同制作规范](共同制作规范.md)。
