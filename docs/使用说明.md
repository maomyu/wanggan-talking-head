# 网感口播正式版使用说明

四个专业skill完整保留，统筹入口负责事实、源映射、版式和运动的交接。正式包独立运行，不依赖test目录。

## 自然语言调用

- “用网感口播处理这段素材，采用杂志画风。”
- “你根据内容选合适的画风，人物原色，角落圆窗，字幕上移。”
- “只把字幕字号增大，其他模块保持。”
- “新增一个画风，先样帧与视频，认可后加入库。”

## 固定运行入口

从实际插件路径执行node scripts/studio.mjs help。doctor检查本包HyperFrames0.8.174、Python库、ffmpeg、字体、四模块与画风库。首次setup只在runtime安装锁定依赖，不安装系统工具。运行基础为Node22+、Python3.11+、ffmpeg/ffprobe；本机已核验。

styles查看分开的认可与候选登记；styles --status approved列出20种，styles --status candidate列出尚未完成方向，styles --all合并查询100种，styles --id A58查看单项。recipe --style A58 --sound S01查看四项展开配方；可用--layout、--motion、--editing、--sound指定profiles.json中的编号。配方是设计建议，不自动生成声音或未实现风格。route --request 中文需求仅作范围提示，由代理按完整上下文判断；可显式--mode full|art-direction|layout|motion|editing。

新素材：init --project 新目录 --source 视频 [--transcript 字幕] [--style magazine]。初始状态awaiting-design；代理按完整skill读懂素材、转写并完成四模块方案和scripts/build-project.mjs，不能拿样例财经文案冒充新内容。运行run --project 项目，依次build、原声与字体、check、render、verify。

明确复现认可案例：init --project 新目录 --example approved --style magazine，然后run。可选择全部已实现方向（包含制作验证）；这个复现器只面向完整认可财经案例，新剪辑或新内容使用custom构建入口。

## 单模块修改

revise --from 原项目 --out 新项目 --module layout --request 具体要求。只在新版本更改所选方案及必要实现，再run。非editing修改保护原始素材、其他模块、总帧数、镜头、字幕语义与时间和原声PCM。确需关联调整，创建版本时用--allow-dependent和--reason记录理由；已有用户授权下继续必要工作。

## 预览与扩展

preview --project 项目返回带Range的真实本机URL；页面可直接在线播放、拖动和全屏，下载单独标明。stop只停止匹配本项目ID的预览服务。

新增画风见新增画风.md，安装状态以Codex插件列表为准。已认可样例与当前范围见组合与范围.md；不会声称穷尽所有画风与组合。

100种方向的详细机制与建议见100种画风与协作配方.md。候选用--source导入，完成设计与样片后按新增流程加入；--example approved拒绝尚无模板的候选，并且不创建残留项目。


当前库：25种已实现（20用户认可，5制作验证），75种未完成。`styles --status implemented`查询可用实现，`--status approved`仅查询用户认可，`--status production`仅查询制作验证。`--example approved`为兼容沿用的固定素材复现命令，两类已实现模板均可使用，不表示都获用户逐条视觉认可。
