# 口播声音协作

声音与画风、排版、动效、剪辑共同工作，优先让人听清意思。这是统筹和剪辑模块使用的完整协作规范，目录S01—S10提供起点；不是已经实现十套音乐生成器，也不代表已有视频新增了配乐。

## 素材与目的

先实际听原音轨，识别说话声、原有音乐、环境、爆音、衣物摩擦和接缝。记录采样率、声道、源区间与可用声音来源。用户未要求新增音乐或音效时，保留清晰原声；有原有音乐时先判断是否需要保留。没有来源或不能生成合适素材时，安静是有效选择，不用占位声音冒充完成。

确定声音要帮助哪件事：承接现场、区分材料、强调一个结果，或维持段落情绪。一次只设一个主要目的。不要因水墨强配古筝、科幻强配轰鸣；音色跟随内容与动作。外部付费生成、授权不明素材和发布不由本规范自动授权。

## 同一时间轴

剪辑先提供源区间与输出帧映射。人声按采样索引裁切，保留中文声母、尾音、呼吸和句间关系；ASR只是候选。自然连续源区间合并，不在每个字幕边界交叉淡化。真的有断点才做不吞字的接缝。不能为贴音乐节拍改变讲话语速或删掉逻辑词。

音效事件至少记录对象、原因、开始帧、时长、增益和来源。翻页、落物、按钮、擦写等可见事件才考虑声音；不是每次转场都嗖一下。声音与动作按意图对齐，允许有理由的提前或余韵，不能盲目要求每个感知事件都机械同帧。需要精确命中的事件以1帧为核对窗口。

音乐建立段落而不主导删句。选择可裁剪的低密度段，关键判断和密集信息处降低或留白；进入和退出保留自然尾音。能通过调整音轨完成的，不扭曲画面时间。没有音乐时仍检查每个转场的人声是否连贯。

## 与四模块交接

画风给材料和情绪，不给刻板配器。排版给读字窗口，避免关键阅读点同时出现抢耳的新声。动效给真实接触、停稳与遮挡帧，声音跟实际事件；删动作要删相应声音。剪辑给语义优先级和真实源断点，任何剪点改变都重映射字幕、音乐和音效。

原色视频轨静音时，仅保留一个独立人声源；不要让播放器、原片和混音同时发声。复现已认可案例默认沿用原音轨，不因为切换画风改变人声音色。新增混音另存版本，保留未处理原声。

## 混音与听感

先人声，再环境，最后音乐与事件音。必要的修复轻量使用，比较处理前后同一句；消噪若让辅音金属化，降低处理量。用耳机和普通扬声器实际听，不能只看波形。环境和音效不要掩盖中频讲话；关键句有音乐则适当压低。动态压缩不以更响为唯一标准。

需要平台交付时按brief检测综合响度与真峰值；未指定可将约−14 LUFS、真峰值不高于−1 dBTP作为工作参考，按实际内容与平台要求调整。纯原声和短片不为凑数过度限幅。报告实际检测值、是否削波和测量工具；没有测过就不写已达标。

## 检查与交付

先只听音频复述内容，再合画面检查嘴型与事件，最后在最终编码MP4中复核。听首尾、每个剪点前后、情绪变化和密集信息段，留意双声、吞字、突然降噪、音乐泵动和尾音被截。最终字幕和声音来自同一版时间轴。

原声保持任务可比较完整解码后的PCM与参考轨；AAC快速seek存在边界差异，不能据此误判剪辑错误。新增混音不再要求与原声整轨相等，应比较人声源映射与可懂度。只报告实际覆盖，不以自动编码通过代替听感审片。交付最终音视频和可重建事件表；只有项目需要时再交独立音乐、音效或混音轨，不能制造无声空文件凑交付。
