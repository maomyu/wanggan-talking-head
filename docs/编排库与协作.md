# 12套编排与四模块协作

100种画风负责材料、字体、色彩和造型；12套编排负责先看哪里、信息怎样展开、何时停稳与怎样交接。12是基础库，可以在真实使用中继续增加。不是每种画风绑定一套不变的模板，也不是12×100已全部实测。

## 选择与取舍

| 编排 | 主要阅读关系 | 适用 | 失败时调整 |
| --- | --- | --- | --- |
| C01 人物留白 | 人物判断→解释→回到人物 | 观点、经验、收束 | 长过程或密证据改用画布/画廊 |
| C02 编辑双栏 | 窄栏判断、宽栏材料、共用对齐轴 | 编辑、复盘、两项比较 | 长中文先按语义换行，不缩成小字 |
| C03 巨字接力 | 完整词组与尺度对照 | 定义、关键词、重音 | 长解释交给图解，不能逐字乱跳 |
| C04 纵向叙事 | 沿纵轴推进，保留前后位置 | 步骤、过程 | 并列只表达阅读次序，不能强连因果 |
| C05 卡片展列 | 同组对象从重叠到并列 | 分类、建议、比较 | 卡片先分开，再让正文完整可读 |
| C06 推导画布 | 对象→关系→判断 | 原理、因果、结构 | 连线必须有事实依据，不漏并列项 |
| C07 画廊取景 | 主图→细节/图注→人物 | 摄影、资料、案例 | 无真实材料时不要硬搭漂亮画框 |
| C08 空间舞台 | 物件有前后，正文平稳 | 材料、结构、空间 | 文字不跟物件侧转，人物不跟镜头转 |
| C09 档案索引 | 固定索引与当前材料页 | 多条资料、规则、档案 | 不伪造档案号、来源、时间或凭证 |
| C10 界面状态 | 面板内概览、选择与提示 | 流程、比较 | 状态要有结果，不伪装真实金融工具 |
| C11 长卷巡览 | 连续卷面、定向移动、停稳 | 连续讲述、历史、步骤 | 到达后读，不让卷外文字遮人 |
| C12 放射结构 | 一个中心、少量并列维度 | 方案、维度、空间 | 长因果链改画布，支线不穿正文 |

选择顺序：先读真实口播的信息关系，检查人物与资料，再选主编排。按每句窗口安排让位、完整显现、停稳与退出。短句先删动作和重复辅助字，不加速人物。全片保持少量共同阅读轴；关系确实改变时可以换兼容编排，不能每句都换一个系统。

画风传材料和字体角色；排版传对象几何、主次和保护区；动效传可见结果、动作区间与完整可读帧；剪辑传真实源区间、切点和阅读窗口。声音遵循[声音协作](声音协作.md)，未要求新声音时保留原声。人物原色、角落全程正圆、字幕上移继续有效。

## 正式入口

从本插件执行以下命令；项目使用插件外独立新目录。

```sh
node scripts/studio.mjs choreographies
node scripts/studio.mjs recipe --style A04 --composition C05 --kind comparison
node scripts/studio.mjs init --project 新目录 --source 视频 --style A04 --composition C05
node scripts/studio.mjs init --project 样例新目录 --example approved --style A04 --composition auto
node scripts/studio.mjs run --project 样例新目录
node scripts/studio.mjs revise --from 原工程 --out 新版本 --module layout --request 字幕上移
```

`auto`读取明确的画风主搭配，不是自动理解新文案。`recipe`依据内容关系列出备选，代理结合真实语义选择。新素材初始化只保存选择并等待本片完整设计，不复制样例台词、7段结构或时间。自然语言指定搭配也按相同规则工作。

固定素材明确使用`--example approved`才能运行随包适配器；`--composition auto`用各画风实际验证的源码版本，显式选其他C编号生成待验证组合。未加composition的旧样例命令仍复现旧版。新组合不会复制旧MP4或通过报告，必须重新检查、渲染和核验。

局部修改仍使用`revise`保护源片、其他模块方案、原声及非剪辑时序。字幕位置和字号由layout-plan.caption实际驱动；复杂标题、人物路径或图解修改由所选模块修改新版本scripts。冻结的director不是任意JSON字段的通用解释器；不能只改一行说明就说画面已经改变。跨系统变更通常牵涉排版、动效和交接，应按整片/相关模块范围另存，记录依赖。

## 已验证与边界

本轮来自研究提交53ce3c6：100个主搭配、453张原生样帧、849个DOM状态；12个代表有新版1080×1920、30fps、1100帧完整视频。旧版100条画风整片证据继续独立保留。原生复合像素严格复现86/100，14项差异保留在[native-final证据](../choreography-library/evidence/native-final.json)，几何检查通过不能抹去这些差异。

这轮源片连续0—1100帧、21条字幕、一条原声，没有新增源片重排、J/L剪辑、音乐和音效。画廊实现主图取景与换位，空间舞台实现材料侧转，界面实现页签和内容状态；不扩大为通用图库、任意真实相机或任意形变引擎。作者自查不冒称独立盲评。

新增基础系统要解决现有库处理不好的实际任务，先用同内容证明空间和注意力差异，再验证动作与交接。只换配色、圆角或小位移不另算一套。正式接入的实际检查另见[1.14.0验收](1.14.0验收.md)。
