# 100种画风与协作配方

100项全部完成同一口播的实际视频与正式模板：20种用户认可、80种制作验证。目录包含材料、摄影、传统风格与原创配方，可按内容组合；不是互斥行业标准或所有世界画风的穷尽清单。

人物保持原色，角落正圆窗，字幕上移；声音默认保留原声。下面的搭配是设计起点，四个完整专家skill负责按真实素材实施。

## 每种的协作配方

### A01 写实极简

真实环境、自然光与克制包装；留白围绕人物的目光。

- 排版：人物主讲。人物承担判断；标题只留一个入口，图解出现时再让位，不遮脸和口型。
- 动效：克制显现。用短距离显现或局部裁切改变注意力，读字时停稳；真人自然表情已提供生命感。
- 剪辑转场：语义直切。完整语句、自然停顿或明确观点变化处接续；不强制每刀踩音乐。
- 声音：原声优先。默认只保留清晰原声与原有环境；没有新增声音任务时不自动加音乐。
- 验证状态：已获用户认可完整视频。

### A02 纸本批注

正文与批线、注释互相对应，阅读像翻看一份有判断的笔记。

- 排版：编辑分栏。标题、原文、批注按栏组织；解释区给更大权重，最多一条主要阅读线。
- 动效：翻阅与批注。纸页、定位线和批注作为关系组动作，批注落到真正对应的句子。
- 剪辑转场：资料覆盖。在相关语句内用真实资料或明确示意图覆盖，读完再离开；人声保持自然连续。
- 声音：轻纸感。可见翻页、纸形落下时才用极轻纸声；不是每个标题出现都加摩擦声。
- 验证状态：已获用户认可完整视频。
