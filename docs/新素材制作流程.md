# 换文案后重新设计动作、图片与转场

这套流程从1.17.0正式执行，承接完整的[语义编排与素材协作](语义编排与素材协作.md)和四个专家模块。用户后续只需给出自己的素材与本次要求，代理负责理解新稿并完成设计和验证。流程约束交接与质量，不把某条样片的分镜、物件、时长或动效参数变成所有新稿的模板。

## 从本片原声与真实意思开始

按[素材与原声](素材与原声.md)选定用户自己的口播，确认唯一制作源。查看实际人物与拍摄条件，依据真实音轨取得转写；网页描述、旧稿或旧片字幕不能代替本片内容。保留原始转写与校正依据，句界和词界来自ASR时注明可靠程度。

先划出实际的主张、前提、解释、例子、对照、转折和结论，保护否定、条件、程度与指代。不是所有口播都同时包含因果、对比和转折；遇到什么关系就设计什么关系。并列建议不能画成因果链，个人经验不能被图形包装成已验证规律，比喻不能假装是测量或真实界面。

剪辑先完成能单独听懂的声音结构，再确定输出窗口与source→output映射。用户要完整视频时，完成约定语义范围的整片；若使用长原片中的一段，交代选择范围与完整论证的起止，不能用几秒片头或样帧代替整片。保留自然语速与表演，不能加速讲话为动作腾时间。

## 把语句变成事件，再决定素材

对关键解释段，用普通话写清“原先什么状态，什么行为改变了它，变化后看见什么，结果如何交给下一段”。对应到实际语句，指出观众要理解的关系与主要注意力位置。一个事件可以跨几句话展开，不按每句换图机械处理。

为本片需要的每项素材分配任务：证据、环境、对象、操作、对照、局部或比喻。图片数量由任务决定。已经在场的对象能够继续推进解释，就让它经历状态变化；确有新的解释缺口时再补图。不要只按名词搜一堆相关图片，再给所有图片套相同的移动、放大与淡出。

表现积累、替换、阻断、分配、反转等行为时，让行为实际发生并留下结果。例如被挡住的路径要真的到不了落点，比较要保持共同尺度，取出的局部要能认出来自哪个整体。目标、过程、完成结果分别表达，避免先展示“已经完成”，随后又无说明地退回未完成的过程。没有这些含义的文案不强加这些动作。

保持需贯穿对象的身份：同一个照片裁片、物件、标记或图形可以先建立，参与变化，暂退为上下文，后文再被回收。后文“从材料中取出一个有用部分”时，画面应能看出对应材料与取出过程，而不是凭空出现另一个通用卡片。若两个对象只是类比关系，则明确它们各是谁，不强迫它们连续变形。

## 四个完整模块共用一份编排

编排表可写进既有plans、分镜或时间文件。至少能读到本次真实语句与锚点、关系、对象身份、起始状态、主要行为、可见结果、图片任务、阅读窗口和下一段交接。不是再建一套与时间轴重复维护的大型系统。

- 画风模块选择适合本片的材料与视觉语言，明确图片如何参与解释，保留真实人物。
- 排版模块安排各状态下的人物、标题、字幕和图解，保护脸、嘴、重要信息以及运动途中路径。用真实文字检查，不能只交一张静帧。
- 动效模块实现起势、运动、结果、停稳与退出，错开主次，检查遮罩、接触反馈、跟随标注与同一对象的前后连续性。
- 剪辑模块按真实语义决定出入点、源片取舍与视觉换场，保留口型与单一原声。源语音剪切和连续人声上的构图变化分别记录。

画风和空间配方可以复用，关键解释需按本片重做。保留旧风格时，不必再进行画风竞选；但旧例的台词、物品、数量、位置和打点不能自动沿用。排版装不下、动作影响阅读或转场改变关系时，回到同一段编排调整，不能各模块分别补一层效果。

## 先验证风险，再完成整片

对新机制或新工具链，先实际编码3—5秒，选择能暴露关键风险的窗口；若本次包含新的真实源剪点，测试需包含它。已经验证的同一机制不重复短测凑流程。原片自己的插图或字幕若遮住人，应依实际帧范围以本片解释画面承接原声，不能冻结、倒放或补造正在说话的人。

完整片段使用一条可重复寻址的时间轴，字幕、动作和源映射读取同一依据。人物原色；角落全程真正正圆；字幕保持上移。图片、标签和标记随所属对象移动，检查路径中间、运动峰值、阅读停稳和前后遮挡。第一帧、最后一帧都成立，结尾不回跳、不黑尾、不吞字。

检查最终实际MP4，并将记录绑定到最终文件哈希。至少核对规格与帧数、原声连续性、字幕安全区、人物颜色及圆窗样本、实际关键交接，以及每0.2秒抽帧和静音结构总览。ASR句级锚点不能被写成逐字一帧精度；抽样也不能写成全量像素相同。正常速度的观看判断与程序检查分别记录。

从最终页面实际播放MP4，检查图片加载、Range、完整原速播放、暂停、跳转和全屏；对照播放保持一路原声，确需浏览器兼容副本时保留原交付并核对声音。修改之后，只能用新文件的检查证明新版本通过。先修语义、断声、遮挡与不可读，再修节奏和细节；无新问题时继续交付，不无限审片。

默认由制作者自查，只有用户或适用流程明确授权时才委派独立评审。认可一条迁移样片不代表所有题材、100种画风和全部自由组合都已验收；实际范围见[1.17.0验收](1.17.0验收.md)。

## 交付、局部修改与清理

交付成片、可在线播放页面、关键拼版、本片设计与统一时间依据、必要的素材来源及检查记录。用户只要一条视频，就完成一条，不自动扩成100版。后续换素材继续本流程；只改字号、颜色或某个动作时保留已经认可的语义和未选模块，另存版本，不强迫整片从头制作。

最终文件和页面验证后，及时清理本项目可重建缓存、密集临时帧、重复代理和失败中间输出；保留原素材、最终文件、页面依赖、可重建源码、关键拼版与检查报告。先确认无任务正在使用，记录清理范围、大小和保留文件哈希，清理后再核对播放入口。不要清空整个qa，不停止无关任务或删除历史成片。
