# 组合、选择与验证范围

四个独立专家skill与一个统筹入口保留全文。风格传材料与造型，排版传层级和保护区，动效传显现与停稳，剪辑传语义区间，声音传原声、环境、音乐与事件位置。全部服从同一时间依据。

## 已确认与候选

A01—A20均有用户认可的完整真人视频及独立实现，继承原色人物、角落正圆窗、上移字幕、同一原声和可播放MP4。新增A16黑板粉笔、A17剪纸舞台、A18巨字海报、A19赛璐璐、A20科幻线框／硬表立体。旧研究别名B01—B05保留查询，不产生重复风格。

未完成的73个方向仍位于extensions，制作中与排队状态分开记录，不含虚构缩略图、实现文件或成片证据。目录包含流派、材料、制作方法与项目创意，组合关系不等于100个互斥学术门类。已有案例不能证明所有新题材和组合都通过。

## 怎么搭配

先读内容：核心是观点、对照、步骤、证据还是情境？再看素材：人物景别、真实资料、可视化对象和可用声音。先选一个主画风；它规定造型和材质。排版、动效、剪辑和声音各选服务本片的一项主逻辑，必要时在章节内变换。

每个方向的profiles是推荐起点，可在style-library/profiles.json中调整：14种排版、14种运动逻辑、10种剪辑逻辑、10种声音方向。它们不是穷尽的模板全集，也不取代完整专家skill。相同配方可以服务不同材料；相同材料也可有不同构图。

例：A58折纸结构可用层叠舞台L10、纸层铰链M09、共同元素交接E04和轻纸感S03；如果原声信息很密，则改S01仅原声，不强行拟音。A94机械剖面可用结构分解L14、模型运动M13、剖面剪辑E10；真实原片与字幕始终不受材质变化影响。

代理自由组合时，记录为什么适合这一句、什么是主要阅读任务、对象怎样接续、何时能读完。发生冲突先保留语义、人物与字幕，再删减次要动作。不能把多套主风格平均堆满一条片。

## 容易混淆的方向

- 复古网点与孔版套印：前者以图像半色调为主，后者以分色版面与套版关系为主。
- 剪纸舞台、撕纸、折纸、立体书：分别靠层间遮挡、纤维切口、折线结构、书脊和机关连接成立。
- 技术蓝图与蓝晒：前者是尺寸、连线与工程结构；后者是物件遮光留下的负形和感光纸。
- 像素游戏与点阵：前者有方形像素场景与角色，后者以圆点、字模和离散刷新为主。
- 单线、钢笔排线与铅笔：分别用连续路径、线密度、石墨轻重和结构辅助线构成画面。
- 柔质立体、陶瓷和充气软雕：体积可以相近，但接触形变、釉面高光、接缝与鼓起受力必须不同。

去掉名字、颜色和装饰后仍应能看出材料、构图或表达机制差异；否则先合并或重做。研究候选时先比较静态构图，再看3—5秒动作，最终拿同一口播做完整视频验证。允许发现某些方向不适合口播后淘汰，不为凑100强行保留。

当前库：27种已实现（20用户认可，7制作验证），73种未完成。`styles --status implemented`查询可用实现，`--status approved`仅查询用户认可，`--status production`仅查询制作验证。`--example approved`为兼容沿用的固定素材复现命令，两类已实现模板均可使用，不表示都获用户逐条视觉认可。
