# 排版模块研究补充：先决定怎样读

用途：在现有完整 talking-head-layout skill 后追加。原专家正文保留；本文件是本轮编排的设计合同，不代替原文，本轮规则现已接入正式插件，验证范围仍按证据区分。

## 角色与任务

你同时负责信息设计和镜头构图。材料相同、主题相同，仍要让观众在第一眼明白谁在说、先读哪句话、图和话是什么关系。不能只替换纹理和字体，然后继续使用同一个标题区、同一个大图框、同一个左右跳动的圆窗。

先读逐句稿、事实来源、人声时间轴、已认可人物与画风。每段只写一个阅读任务：判断、比较、顺序、因果、证据、空间或收束。任务决定版式，画风负责让版式成立。不要因为画风叫蓝图就把并列建议画成因果，也不要因为叫杂志就把每句旁白排成一页密集正文。

## 不变条件

- 真人素材保留原色、身份和长宽比例。角落人物全程正圆；背景、物件可以受画风影响，真人不接受滤镜或扁平化。
- 本次9:16案例字幕左64、顶1600、宽952、60px，最多两行，实际字框下边不越1800。其他画幅重新排版，不按比例裁掉。
- 普通字幕承担逐句听读，表现文字承担判断或结构。两者可以同词，但不能同时争抢同一阅读中心。
- 真证据与解释示意分开。资料需要来源，示意图不能伪装收益记录、真实账户或第三方背书。

## 12套可组合的空间语法

| 系统 | 第一眼与人物 | 停稳状态 | 适用与失败信号 |
|---|---|---|---|
| C01人物留白 | 开场/结论大人物，解释时让到右下 | 观点在上，解释主体居中 | 判断、劝告、经验；失败是人物缩小但没有新增必要信息 |
| C02编辑双栏 | 窄栏观点，宽栏资料，人物在窄栏底部 | 栏线作为跨段落的共同轴 | 编辑、笔记、复盘；失败是长标题挤窄栏、宽栏只剩空板 |
| C03巨字接力 | 完整词组占主画面，人物居角落 | 词组之间靠位置和字号建立关系 | 定义、对照、重音；失败是拆字妨碍理解或一句话铺满四层 |
| C04纵向叙事 | 眼睛沿纵轴向下，人物固定于阅读线外 | 节点留有前后位置记忆 | 次序、过程；失败是把并列事项暗示成必然因果 |
| C05卡片展列 | 先看整体，展开后看同一组对象 | 每卡一个概念，副句靠近对应标题 | 分类、三项建议、对比；失败是卡片展开时正文已在互相遮挡 |
| C06推导画布 | 先对象，再关系，再判断 | 对象与连线端点绑定 | 原理、因果、结构；失败是箭头与真实逻辑无关 |
| C07画廊取景 | 图像得到主面积，人物让出证据区 | 全貌/局部的图注随选择变化 | 资料、摄影、案例；失败是无资料时硬搭漂亮画框 |
| C08空间舞台 | 物件在上，稳定文字在下，人物独立 | 正文不跟物件侧转 | 材料、结构、空间；失败是运动很多但文字被透视压扁 |
| C09档案索引 | 左侧索引常驻，右侧当前内容 | 标题、材料、摘录有固定对齐 | 多项资料、规则、年鉴；失败是装饰编号看起来像真实档案号 |
| C10界面状态 | 活动页签解释当前段落 | 面板边界和内容变化有对应结果 | 流程、选择、比较；失败是没有真实功能却画成可操作金融工具 |
| C11长卷巡览 | 视线沿一条连续卷面移动 | 上文保留位置，当前段停稳可读 | 连续讲述、历史、步骤；失败是滚动速度超过阅读能力 |
| C12放射结构 | 一个中心，少量并列分支 | 重要性靠距离和字号表达 | 维度、方案、选择；失败是每根线都画成箭头，造成虚假因果 |

## 从选型到画面

1. 写出本段的信息关系与一句理由，再选主语法。全片不必一段一个新布局；同一关系可以保持，关系变化才换。
2. 给人物、标题、字幕、图像、图解各写责任和让位条件。先以无材质线框排出阅读顺序，再恢复画风。
3. 先做开场、信息最密、最大关系变化三个状态。用同一句字幕、同一素材对照，不能靠内容不同制造差异。
4. 检查实际字体的字框和换行。中文字体必须包含真实文字；字体名相同不代表回退没有发生。
5. 提交layout-plan：状态/阅读任务/主次顺序/对象矩形/人物保护区/字幕保护区/进入和交接时允许的占区变化/来源/验证帧。

## 版式与动效交接

起止矩形必须明确；途中可以越过尚未显现的对象区域，不能越过正在阅读的人脸、正文和字幕。卡片先分开，随后显字；翻转时清空正文，读字时回到稳定平面。跨镜保留对象身份与对齐轴，不能只用同色装成连续对象。

## 自查与失败回退

先修阅读冲突、缺字、人物遮挡，再调美感。用真实1080画面与手机实际缩小视图都看一遍。去色后若12套仍像同一模板，应改变阅读主角和空间关系，继续换颜色没有帮助。

本轮100条使用12种主语法，材料与字体各自继承；不是100套互斥排版，也不是12×100个组合全部经过验证。程序记录4个语义状态与反向seek；短片额外检查动作中间帧。抽样的通过不升级为全帧无碰撞证明。
