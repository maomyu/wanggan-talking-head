# 新素材迁移方法的认可记录

本次用户认可的是“按新文案重设计动作、图片和转场”的完整方法，同时明确要求后续继续用自己的口播。正式执行见[新素材制作流程](../../docs/新素材制作流程.md)和[素材与原声](../../docs/素材与原声.md)，实际范围见[1.17.0验收](../../docs/1.17.0验收.md)。

本目录只保存方法决策和有界数值证据，不保存第三方人物视频、声音、逐字稿或可被误当默认模板的完整台词工程。第三方62.7秒测试保留在本地历史test；它证明一次迁移的实际完成，不替代用户的生产素材。自有36.7秒整片与原始上传文件的对应信息见[evidence/user-source.json](evidence/user-source.json)。

[用户本轮认可](evidence/user-approval.json)记录认可范围与素材选择。new-source系列为历史迁移测试实际编码、原声、圆窗和在线播放证据；user-film系列为已完成自有素材整片的证据。两者各自绑定实际MP4哈希，不能把这些旧报告直接当作未来新片验收。当前认可不意味着100种画风全部按新方法重做，也不意味着所有题材与自由组合都通过。

[本轮入口与构建检查](evidence/release-entry-check.json)记录用自有源片完成的8项隔离检查；它验证方法入口、构建兼容性、原声保护与源片绑定，不属于一次新影片渲染。
