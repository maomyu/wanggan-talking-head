# 12套基础编排与100种画风的协作

12是基础系统数量，100是画风材料数量，不能按一对一理解。基础系统负责“观众先看哪里、信息如何展开、何时停稳、怎样交接”；画风负责色彩、字体、材料、边缘和图形语言。同一系统在开场、双项对照、三项并列、风险判断、短句和收束时有不同状态，不是整片固定一个模板。

本轮在test研究。正式插件1.13.0、四个完整专家正文和已认可的原视频保留。这里新增的是可执行的研究入口、完整编排规则、100个明确主搭配，以及12个代表方案的整片实测；验证状态以当前实际文件为准。

## 选择顺序

1. 先读懂真实口播：这句话要表达判断、比较、过程、因果、并列、证据还是空间关系。区分“先后出现”与“事实上的因果”。
2. 识别需要看的材料：人物表情、长文字、图片细节、图表还是空间对象。材料的真实复杂度比画风名字更影响排版。
3. 选一套主要编排，必要时给解释段换一套兼容编排。先保持人物保护区、阅读轴、字幕位置和连续原声，再设计交接。
4. 按这句话的真实时间计算动作预算：让位 → 完整显现 → 停稳阅读 → 退场。短句先删动作、删重复辅助文字，不能让人物说快来迁就动画。
5. 先做当前片子的真实关键帧与短测，再渲染整片。目录建议不是已通过的全部组合。

## 适用关系

| 讲述任务 | 优先考虑 | 判断要点 |
| --- | --- | --- |
| 个人观点、结论 | 人物留白、巨字接力 | 保留表情，关键词少而完整 |
| 两项选择或前后对比 | 编辑双栏、卡片展列、界面状态 | 两项同时可读，区别明确 |
| 时间过程、步骤 | 纵向叙事、长卷巡览 | 方向一致，保留已读位置 |
| 原理、依据与结果 | 推导画布 | 节点先出现，连接有事实依据 |
| 图片、材料、来源 | 画廊取景、档案索引 | 看清主图和图注，来源不伪造 |
| 空间对象、并列维度 | 空间舞台、放射结构 | 文字不跟物件歪斜，支线不穿字 |

## 四个模块怎样共同工作

画风模块提供真实材料、字体角色、前景/底色与边缘规则。它不决定每一句都把图放在同一位置。人物始终保留原片颜色与比例，风格不能套到人物身上。

排版模块针对当前阅读任务给出空间状态：谁是主角、哪些信息同时可见、人物起落点、标题与图解关系、字幕保护区。窄栏中文必须按语义断行，不能把一个汉字孤零零留在下一行。

动效模块在这些已成立的空间状态之间组织让位和显现。人物大幅移动时不同时读密图；卡片先落稳再读字；连线在节点之后生长；卷面走完再阅读。每个状态从绝对帧计算，反向寻址也要核查旧材料层。

剪辑转场模块优先保障原意、人声和阅读窗口。本轮原片连续0—1100帧，只有画面编排变化，没有新源片拼接。共同栏线、同一卡片、稳定页签、同一中心或空间轴承担交接；不把视觉切换冒称J/L剪辑。

声音继续使用同一条原声。本轮没有新增音乐和音效；后续确有任务再按正式声音协作规范设计，不能每刀固定配嗖声。

## 本轮实际边界

- 卡片展列、连续长卷、UI页签与固定面板、中心轴侧转、节点/连线、词组接力均已有实际实现。
- 画廊本轮实现主图取景与换位，未声称通用多图连续轨道；空间舞台没有声称任意模型/真实相机引擎；UI没有声称任意面板形变。
- 100项各有明确主编排和本片内容方案，原生样帧与源码绑定；完整MP4只对12个代表方案验证。100×12自由组合未全测。
- 换新文案时需重新转写、校正语义、设计图解与时间轴。当前固定素材适配器有源哈希保护，不会把财经台词套给其他视频。通用能力来自完整四模块设计流程，不能把一个样例适配器说成任意文案全自动剪辑。

## 统一研究入口

`node scripts/studio.mjs systems`查看12套完整规则。

`node scripts/studio.mjs recipe --style A04 --kind comparison`查看杂志画风的主搭配、内容适配条件及候选。可用`--system C05`明确指定；候选需要本片验证。

`node scripts/studio.mjs apply --from 原工程 --out 独立新版本 --system C05`将当前固定素材工程另存并切编排。保护原工程，不覆盖已有输出；新版本仍需构建、检查、编码和解码验收。

`node scripts/studio.mjs delegate --command doctor`调用正式插件固定运行环境。整片制作和单模块修改继续委托正式`init/revise/run`，读取四个完整专家skill，研究入口不替代它们。

新增基础系统应回答一个现有系统处理不好的实际任务，并以同内容对照证明差别；不为了凑100套把颜色、圆角或轻微位移记成新编排。

## C01 人物留白

人物承担判断，重点贴近目光，解释只在需要时接管画面。

已实现状态：主体近景 → 连续缩放让位 → 图解 → 回到人物。

动效：圆窗匀比移动；图解延后显现；结论近景停留。

交接：观点处直切，解释收完再回人，不按句子机械换场

适用边界：长过程、大量证据或多项同时比较时换其他编排。

## C02 编辑双栏

窄栏放判断，宽栏放图像；文字与图片共享跨段落的对齐轴。

已实现状态：宽幅开场 → 左判断右解释 → 并列词列 → 跨栏收束。

动效：基线换词；图注错峰；栏线锚点遮挡交接。

交接：按完整论点翻到下一版，保留栏线作共同锚点

适用边界：长中文先语义断行；窄栏不能靠缩小字号塞入。

## C03 巨字接力

关键词占据主画面，字与字的尺度和位置承担讲述，人物让出阅读中心。

已实现状态：大词组提问 → 多行接力 → 两词对峙 → 巨字判断。

动效：词组掩膜与短横移；主次尺度对照；完整词组停稳。

交接：在语义重音处切表现文字；人声不另切、不开倍速

适用边界：超过一句解释、图表或证据细节不能强塞巨字；不逐字乱跳。

## C04 纵向叙事

问题、行为和后果沿纵轴展开，读过的部分留下位置记忆。

已实现状态：完整路径 → 节点依次显现 → 结果落点。

动效：节点错峰；单轴视线推进；路径保留。

交接：在同一叙事空间里推进；转折保留一个停稳窗口

适用边界：并列建议只能标阅读顺序，不擅自连成因果。

## C05 卡片展列

同一组信息由重叠变为并列，让观众看见原本被藏住的关系。

已实现状态：重叠概览 → 边缘分离 → 卡片展列 → 归纳。

动效：旋转回正；卡片展列；落稳后显字；共同卡片遮挡交接。

交接：用同一卡片换层级，不能用三张无关图假装同一物体

适用边界：短句窗口缩短入场；卡片展开后要给正文真实阅读时间。

## C06 推导画布

主张、依据和结果在同一张画布内建立对应，保留已读上下文。

已实现状态：对象 → 建立对应 → 双项或三项标签 → 判断。

动效：节点后连线生长；关系停稳；中心对齐交接。

交接：按推导完成程度推进；并列建议不连成因果

适用边界：没有事实支持不连因果；并列三项不能遗漏一项。

## C07 画廊取景

图片获得足够面积；主图与备选画面共享一条连续展示轨道。

已实现状态：完整主图 → 主图换位 → 图注 → 回到人物。

动效：取景框内换位；图注与图片同步；停稳看细节。

交接：全貌到细节再回人物；解释图不冒充真实凭证

适用边界：本轮是主图取景与换位，尚未实现多张独立图片的连续图库轨道。

## C08 空间舞台

材料物件有前后层次，正文在稳定平面，人物独立于场景镜头。

已实现状态：总览对象 → 侧转换态 → 正面阅读 → 收束。

动效：中心轴侧转；边缘按角度淡出；正面标签停稳。

交接：边缘侧转处换图解，下一镜保持空间轴线

适用边界：本轮是素材组侧转与原有物件渲染；不是通用真实相机或任意模型引擎。

## C09 档案索引

左侧索引保持，右侧材料展开；编号只是位置索引，不伪造档案事实。

已实现状态：稳定索引 → 右侧材料 → 摘录判断。

动效：同入口抽页；索引保持；页签遮挡交接。

交接：按照材料与观点组织段落，共同页签接续

适用边界：索引为位置导航，不伪造档案编号、来源、日期或凭证。

## C10 界面状态

同一解释面板在总览、对照、风险提示之间变换，状态有可见结果。

已实现状态：概览面板 → 活动页签 → 两项对比 → 风险提示。

动效：指示条伸缩交接；内容分组显现；面板内状态替换。

交接：状态变化承担转场；不虚构按钮操作与真实理财数据

适用边界：本轮面板与指示条切换已实现；不宣称任意形变或真实产品交互。

## C11 长卷巡览

三条建议属于同一条展开的长卷，镜头只移向本句需要的位置。

已实现状态：卷首 → 同一长卷中段 → 卷末回望。

动效：单向长卷位移；窗口停稳；独立标题与字幕。

交接：用连续空间取代整页清空；句尾留停稳再巡览

适用边界：视口裁切有意为之；未进入视口的字不算已展示，禁止卷外文字遮人。

## C12 放射结构

中心只有一个主张，周围是并列的选择或维度，层级靠距离建立。

已实现状态：中心 → 周围分支 → 局部强调 → 完整关系。

动效：分支错峰；局部到整体；中心持续锚定。

交接：共同中心保持，分支轮换而非每条重建全图

适用边界：多层嵌套、长句或长因果链应换推导画布；不让支线穿字。
