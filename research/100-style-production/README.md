当前正式34种：20种用户认可，14种制作验证；另66种尚未完成。目标仍是100种实际视频和正式整合，不把文字方向计作完成。

第二批新增A76木刻刀痕、A78孔版套印、A80蓝晒图像、A95终端字符、A96矢量示波、A97低帧点阵、A98早期桌面。各完成1080×1920/30fps/1100帧真实整片，保留人物原色、角落正圆窗、字幕上移与原声；每条183张5fps密集帧、18剪点邻帧、首末帧、人声与人物颜色均有实际检查记录。作者查看真实编码拼版、关键交接和负债段，没有独立盲评，也没有宣称新增14种获用户逐条视觉认可。

本批额外验证：7种实际图解像素在反向跳转后相同，主要阅读角色对比度不低于4.5；7种新模板声明实际人物基础几何和data-person-travel参数。正式早期桌面模板的motion单模块修改已实际生效，并保护其他方案、原声、字幕、总帧数与停稳图解；附属说明等人物停稳后显现。该行为是实际抽检，不冒称所有任意组合全面验收。

修正记录包括孔版过闷、矢量物件标记不足、附属说明与较慢人物移动竞争、字符图案被误当正文导致的17处重叠检查及首次检查截止。字符保留原字体轮廓与密度作为图形复用，可读标题字幕仍做完整检查；未删除检查或把未通过版本算作完成。
